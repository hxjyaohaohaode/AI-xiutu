# 内容工作台：V3 真实交互与能力边界

本文描述当前源码的数据与操作链路。V2 旧说明已归档于 [interaction-v2.md](verification/interaction-v2.md)，不再作为当前能力清单。配方及预算以 [V3.md](../packages/editor/V3.md)、[编辑器 README](../packages/editor/README.md) 为准；人物算法以 [人物模块](../packages/portrait/README.md) 为准；服务器权限、结果决定与恢复以 [API.md](../apps/api/API.md) 为准。

本轮六轮完整回归、真实浏览器过程及失败边界统一由 [VERIFICATION.md](VERIFICATION.md) 记录。本文不预先声称六轮已通过，也不把旧五轮记录、单元测试替身或文档调研算作本轮真实验收。

## 1. 作品优先，工具逐级展开

默认工作面是照片、顶部动作与底部工具。美颜位于工具顶层；明暗、色彩、曲线、构图、局部、细节、绘制、液化、合成、记录共享原图和版本化配方。AI 使用明确选择的项目、作品版本、参考图片、草图和文档上下文。

工具内部以微小中性色阶、文字和图标表达选中状态。面板保留一个主要外边界，内部类别、参数与对象列表以留白和色面分层。裁切手柄、蒙版轮廓、曲线网格属于操作反馈，不为减少框线而取消。

操作路径是“工具族 → 子类/对象 → 当前参数”。ParameterShelf 显示同类参数名称和数值，主滑条一次只服务当前参数。切换参数会提交有效预览；颜色、名称、精确坐标和高级设置按需展开。手机宽度≤759px或实际工具面板高度≤420px时，主滑条优先，候选参数成为单行横向工具带，直方图及辅助说明后置。必要时只滚动调参容器使主控可见，不滚整页。

PrecisionRange 方向键按字段步长，Shift 加速，Alt 细化，整数字段仍保持整数。点击数值进入精确输入，Enter 确认、Escape 放弃未确认的数值。拖动有单一指针所有权，第二根手指不能结束第一根手指的操作。Escape、指针取消、丢失捕获、窗口失焦恢复该次操作起点；卸载或换源丢弃旧所有权，防止旧值写到下一张图。迟到事件不再提交已经取消的配方。

## 2. 自由面板与独立设备布局

面板宽高按实际工作区和可达性计算，没有固定的 330px 上限或几个尺寸档位。手机也可改宽、高，选择浮动、左、右、底部停靠。标题移动、八边角缩放、尺寸滑条操作同一布局数据。提供最大化/还原、折叠/展开、恢复当前面板初始布局。

| 内容     | 桌面                                                | 平板               | 窄手机与短横屏                  |
| -------- | --------------------------------------------------- | ------------------ | ------------------------------- |
| 初始构成 | 照片中央，侧边当前工具                              | 照片与单工具共存   | 默认底部参数，保留主要画面      |
| 自由度   | 任意停靠/浮动与连续宽高位置                         | 独立尺寸和触达间距 | 同样可以调宽高/停靠，短高度另算 |
| 图像关系 | 停靠严格让位，或主动自由叠放                        | 按真实安全区拟合   | 大面板可临时收起看全图，再恢复参数 |
| 键盘     | 标题移动、右下角缩放；默认 8px、Shift 32px、Alt 1px | 相同逻辑           | 外接键盘可用，触摸把手独立尺寸  |
| 偏好     | 按面板保存                                          | 与桌面偏好分开     | 按宽度档和横竖屏分别保存        |

停靠选择“画面自动让位”时，即使可见空间紧张也不自动转为覆盖。原有折叠按钮在紧凑状态明确提示“看全图”；收为44px标题栏后可“继续调节”，恢复之前的连续尺寸与参数。用户主动浮动、自由叠放或最大化仍可覆盖照片。

移动面板不修改图片，裁切和变换才修改输出。实际工作区测量、窗口和 VisualViewport 一起约束边界；软键盘出现不会覆盖永久布局偏好。宽度档目前是 `<760px` 手机、`760–1119px` 平板、`≥1120px` 桌面，短高度另做处理。这是布局策略，并不是每种硬件已实测的证明，实际验收尺寸与操作见验证记录。

## 3. 全图、多个局部与组的完整调色

V3 每个独立局部和组都有完整 ColorBlock：基础影调、输入/输出色阶、RGB 四通道曲线、八段连续混合 HSL、三路色彩分级、纹理/清晰度、锐化/柔化、降噪、色散、暗角、颗粒、黑白和褪色。“整张照片 / 单个局部 / 局部分组”选择同一套参数的作用位置，修改一处不会覆盖其他范围。

组参数作用于有效成员范围的并集，成员自己的参数仍保留。可以多选编组、调组透明度、命名、隐藏、解组。解组移除组调整但保留各局部并可撤销，不是把所有成员数值强制同步。

| 范围     | 直接操作               | 精细参数及组合                                    |
| -------- | ---------------------- | ------------------------------------------------- |
| 径向     | 拖中心及轴端           | X/Y、双轴半径、羽化、反选；半径最小值使用内核范围 |
| 线性     | 拖起点和终点           | 四个坐标、平滑过渡、反选                          |
| 多边形   | 移点、插点             | 点坐标、删点、羽化，最多 64 点                    |
| 画笔     | 涂入/擦除              | 原图像素直径、柔边、流量，支持 1px 直径           |
| 连续颜色 | 原图取色或完整色谱     | 色相 0–360°、容差 0–180°、饱和/明度上下限、羽化   |
| 栅格标注 | 读取分析或标准配方 RLE | 反选，并通过组合画笔/形状补修                     |
| 组合范围 | 在树中选当前子区       | 相加、相交、相减、互斥、嵌套，保留子节点          |

每个范围可复制、排序、命名、隐藏、删除和撤销。组合路径编辑保留兄弟节点，陈旧路径不能写入错误子区。当前有 12 个局部、6 个组、全配方 128 个蒙版节点、深度 4 的预算；组合节点有 2–8 个孩子，笔画/RLE 另有复杂度限制。预算统一由解析器强制，不能只放开 UI 后忽略手机内存或导出成本。

## 4. 自由构图、曲线与像素精度

裁切使用定向后原图整数像素。画面手柄与宽高、左上边界修改同一矩形，常见比例只提供起点，之后任意改宽高。裁切不受 AI 模型输出尺寸约束。

V3 有连续旋转、水平/垂直透视、双轴斜切、双轴缩放和平移；角度可以按 0.01° 细调，保留 90° 旋转和镜像快捷入口。完整变换画幅与保留裁切画幅分别决定输出。奇异、退化或超预算的变换在预览前拒绝并保留上一个有效状态。透明空白仍是透明像素，不称为 AI 扩图。

RGB 主曲线及 R/G/B 各有 2–16 点，Y 可上下变化或反相，X 严格递增，保证一个输入只有一个输出。拖动、双击添点、点选择、精确输入、键盘、删除、预设操作同一曲线，全图/局部/组均可用。当前线性插值，没有独立亮度曲线或任意贝塞尔手柄。手势绑定原图身份、整个配方、通道和作用范围，中途变化后旧事件不可回写。

完整色谱包括连续 SV 平面、色相、透明度、RGBA/HSV/HSL 数值、3/4/6/8 位 HEX。常用色板只是快捷入口；八段 HSL 不是系统只识别八种颜色。连续选区可以指定任意色相与容差。色谱支持键盘和单一指针取消；转换测试覆盖色立方样本、720 个半度色相与全部 256 个 alpha 字节。

绘制最小直径为 1 个原图像素，硬边对齐像素中心；X/Y 整数坐标支持明确落笔与设置克隆源。缩小预览时，一个原图像素未必肉眼可见，原尺寸导出才验证其实际范围。“像素级”不表示单个像素具有独立几何尺寸，尺寸由裁切、重采样和变换决定。

当前确定性工作精度是 sRGB/RGBA8。能解码某文件不等于 RAW 显影、16/32 位浮点、P3/HDR、ICC 或 CMYK 已具备完整链路。能力提示应先于昂贵处理，预览和输出使用同一参考内核。

## 5. 绘制、合成、液化与保护

绘制层支持画笔、橡皮、克隆，独立颜色/alpha、透明度、蒙版、名称和顺序。笔触保存提交时配置，调画笔大小不反改已有笔触。克隆必须选来源，以绘制前图像采样，避免不断复制自身；它是克隆修补，不是已实现的自动祛痘或神经修复。

图片合成层保存自己的 sourceId、位置、宽高、旋转、镜像、透明度与蒙版。可导入、复制、排序、隐藏和删除，底图及引用层共同保存。历史须加载各自真实来源。AI 图片可显式作为合成层加入，而不替换底图。

两类层均支持 16 种混合：正常、正片叠底、滤色、叠加、柔光、强光、变暗、变亮、差值、排除、颜色减淡、颜色加深、色相、饱和度、颜色、明度。蒙版从局部复制后是独立副本，不承诺实时联动。

液化支持推动、收缩、膨胀、旋转，强度有正负方向，笔画保存、可隐藏和撤销。保护区可手绘或复制局部，调羽化、反选和组合节点。保护不保证夸张形变无痕，纹理质量仍要实际判断。

当前预算是 24 个绘制层、128 条绘制笔画、8 个图片层、64 次变形，另有点数和计算预算；图层导入还有每层与会话解码预算。超限明确失败，不静默丢旧笔触或伪造成功。

## 6. 人物分析与独立精修

分析与像素渲染分离。分析结果绑定原图完整哈希、尺寸、方向、提供方、算法版本和结构，由适配器调用 Worker。没有检测结果时不能用虚构矩形代替成功。脸和身体是不同类型目标，不能按索引假定为同一人。选择目标后，仅满足可见锚点条件的参数可用，缺项显示原因。

美肤、面部、身形、美妆由人物目录驱动，转换为标准局部调色、绘制蒙版和位移笔画。各妆容颜色独立，修改口红不重涂其他妆容。分割仅是初选范围，遮挡、低光、低分辨率及多人重叠仍需检查。

`portrait.basic.v1 + instanceId` 表示自动操作所有权。同一人物再次调参会替换自己的自动操作，避免每拖一次便叠加效果。其他人物与普通手工层不应被重建。需要深度手修时使用“当前人物转为独立精修”，一次性脱离该人物整套自动局部、妆容和形变的所有权，保留当前像素、来源和撤销历史，之后继续手改。不能只分离一项又从其他项的整套元数据读回参数。转为独立后自动滑条中性，重新使用自动参数是在固定结果上加新一轮效果，界面须说明。

“人物标注与分析接入”折叠区提供真实文件导入/导出。导入只接受与当前原图完全匹配的支持提供方/版本，不记为浏览器自动识别成功，可用于分析备份、复现和标准外部分析接入。普通用户不必面对 JSON 文本墙。

本轮浏览器实测限制：原生分析输入路径需要 OffscreenCanvas 和 WebGL2，即使 CPU delegate 也不能推定不需要图形上下文。本次受限浏览器出现 WebGL 不可用，须提示并允许手工继续。真实 CPU 模型标注经导入可以验证编译/渲染，不能替代浏览器原生自动推理成功证据，具体过程见验证记录。

这是可替换、有来源的基础算法，不声称已达到醒图/美图闭源商业质量。自动瑕疵检测、神经毛孔重建、精细头发分割与任意多人遮挡仍需进一步算法与数据集验收。

## 7. AI 候选进入项目

图片生成/编辑、草图、文本、调整建议、语音识别及语音输出遵循服务端模型能力目录。模型 ID、参数枚举、范围和可用性由配置决定，截图选项不会无条件发给所有模型。

| 决定         | 真实动作                       | 保护                                   |
| ------------ | ------------------------------ | -------------------------------------- |
| 暂不采用     | 保留候选并记录决定             | 不自动退款或重生图                     |
| 另存作品     | 独立作品分支                   | 不覆盖当前未保存编辑                   |
| 替换当前作品 | 候选原图加中性 V3 配方的新版本 | CAS；旧源图和配方保留                  |
| 作为合成图层 | 底图/编辑保留，增加独立引用层  | 同项目 ACL、CAS、图层预算              |
| 采纳建议     | 基于绑定作品和基准版本建新版本 | 拒绝过期或错作品建议                   |
| 保存文本     | 新文档或显式指定文档版本更新   | 原输出保留；手动修改记录 contentEdited |

所有决定带 protocolVersion 和 idempotencyKey。不明确的网络响应重试同一决定，不重发收费 AI 任务。有未保存编辑时不可替换/合成/采纳，先保存或另存。服务器重查权限、资源和版本。

文本先编辑再保存是用户修改结果，不能声称仍是已审核的原始输出。语音先录制、试听、识别、确认文本，再进入用户选择的任务，不自动把一句话变成多次收费请求。未配置真实模型/审核/账户时显示缺项，无演示图片、假成功或固定费用。

## 8. 版本、组织和验证

修订含自己的 source assetId 与配方。打开历史先取该修订源图和图层，再加载配方；恢复创建新修订并使用期望版本，不抹掉后来的历史。本地撤销与云端历史有不同入口。

个人/团队统一导航但权限、项目和钱包隔离。素材、文档、任务、讨论、评审与交付按项目连接；搜索和游标按服务器真实范围工作。标题/标签、声明的拍摄时间/位置、服务器时间和不可变字节分开保存，未提供的定位不推断。

可靠协作目前依靠权限、CAS、不可变修订、决定记录和持久事件。实时同像素多人合并、跨图依赖自动传播、直播/视频处理尚未完成。静态照片即时预览不等于直播。

预览有背压和源身份/结果过期检查，真实未完成时显示计算状态。动效见 [MOTION.md](../apps/web/MOTION.md)。本轮六轮的命令、结果、失败修复、浏览器操作、CPU 标注与原生推理差异，以及真实短信/账户/付款/大陆网络等外部验收边界，最终以 [VERIFICATION.md](VERIFICATION.md) 为证据。后续算法、瓦片、格式、文字矢量或实时协作沿统一契约扩展，不能重新堆互不连通的演示模块。
