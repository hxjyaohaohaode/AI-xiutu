# AI 修图功能对照与验收主表

核查日期为 2026-11-11。AI-xiutu 以 [45ce38f][ours-head] 为代码基线，经 [PR #8][pr8] 合入 `main`。包含前端 [PR #7][pr7] 及 [PR #9][pr9] 的 `1a633e0`。以后以本表编号关联需求、PR 和验收记录。旧调研正文、完整附件和原始截图用于确定覆盖范围。

**读表**　每行对应一个能验收的结果。**已验**表示括号所列路径已有执行证据，**部分**表示已有执行路径但能力或质量还差一段，**待验**表示代码已接通但缺对应的端到端证据，**缺口**表示未找到能完成该目标的产品路径。竞品栏的 **—** 表示本轮一手资料未确认到该能力或细节。竞品同名功能按实际入口、参数和结果记录。机型、区域和平台沿用来源范围。

**更新标准**　P0 为会影响原图清晰度、编辑正确性、用户明确提出的核心质量或发布闭环的项目。P1 为高频功能深度。P2 为扩展工作流。P3 为需明确产品范围或研究授权的项目。完成时在原行填写实测提交、设备或样本、结果和证据链接。表内新增样本数、延迟等为下一轮可重复验收的目标。旧样本成绩保留其原测试条件。
