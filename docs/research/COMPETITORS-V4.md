## 对界面与联动的直接约束

手机使用与底部工具栏相连的上下文面板；调节类别在面板内切换，选择一个参数时主滑条立即可见。面板高度和宽度连续调节，默认停靠给照片让位，用户可以明确选择浮动/叠放以精调。收起只改变呈现状态，恢复原尺寸、参数和当前目标。桌面保留可移动浮动工具，平板按实际宽高与输入方式约束，不把桌面像素尺寸直接缩到手机。

所有可见调整最终进入版本化配方；云端共享写入由后端租约和版本校验决定。鼠标移动和临时预览不产生账本消费，确定的编辑命令才生成版本。模型输入画面是用户明确共享的当前渲染快照，包含未保存参数，但绑定源图、作品版本与配方摘要；AI 提议仍须明确采纳，不能成为绕过协作占用的写入后门。

素材库、个人长期标注、团队成员动态和用量报表是各自的真实 API 视图。长期标注只属于当前账号，不能反向授予原素材权限；预占累计额不能当钱包当前余额；CSV 必须继续跟随服务器快照游标，不能把第一页当成完整导出。专业原件与代理图分开显示，保留 16 位母版不等于已经把代理图编辑无损回写到母版。
