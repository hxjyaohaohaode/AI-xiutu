## 4. 重点回归反例

- 看不到项目的人、被撤销成员或仅具平台运营身份的人，不能凭资产 ID 读取私人原图与缩略图。
- 同一版本竞争保存返回冲突；照片配方和文档版本不可原地覆盖。元数据注释也检查期望版本。
- 资产列表游标绑定空间/项目、查询、来源和日期条件；每一页重新检查权限，游标不充当访问授权。
- 选区参数和蒙版都保留在 v2 配方；迁移旧配方保留旧算法语义，不静默改为新算法。
- 真正单像素蒙版的外部 RGBA 字节不变；色域选区始终参考未修改的源像素，不因全局或前一个区域的调色而漂移。
- 连续 HSL 在色相零点连续；透明像素不因反选色域而意外入选；纹理、清晰度、分块邻域与整图坐标一致。
- 曲线旧拖动的 move/up/cancel/lost-capture 事件不能把外部新编辑回滚；重复指针不能接管已有手势。
- 完整参考渲染与分块结果对所有 v2 阶段和非整除分块边界逐字节一致；最大细节依赖使用 12 像素 halo，分块仅复用两个 Float32 工作缓冲。
- 重复幂等键不重复占点；旧键搭配不同输入拒绝；过期免费周期的释放不变成下一周期的可花额度。
- 输入审核拒绝时不调用收费模型；图片批次必须全部通过审核才统一发布和结算，不提前泄露半个批次。
- 供应商已执行但后续审核/提交不明时保留 unknown 与回执，不自动重发可能已经计费的请求。
- 发布文件的事务与失败清理使用同一 storage key 锁；清理等待原事务结束并检查全部资产记录引用。COMMIT 确认丢失时已发布文件仍可读取；无法确认引用时保留私有文件。
- v2 AI 参数提议只允许实际 65 个数值路径；有限数值、重复路径、整数项、耦合色阶范围和协议版本都重新校验。用户确认依据是实际参数差异与作品版本。
- OpenAI 各模型支持项、批次数、总像素、参考格式、同尺寸蒙版/markup、单次报价预算经过前后端约束；不支持的参数不会因为界面摆出控件而假装有效。

实际使用了建筑、花卉、人像照片，以及 PNG/WebP/AVIF 技术构图，工作台不预置测试作品。检查尺寸为 320×700、390×844、768×1024、844×390、1024×768、1440×900，另有 1363×936 主桌面；应用根页面的滚动宽高与视口一致。照片本身及祖先未被模糊滤镜影响。

## 6. 已知工程和外部验收限制

- 主 JavaScript 生产包仍为约 **861.74kB（gzip 238.42kB）**，保留超过 500kB 的构建提示。下一步应继续拆分主工作台并在实际手机、弱网测首屏；本次没有报告虚构的帧率、延迟或移动性能分数。
- 当前预览以 RGBA8/sRGB 输入为基础，v2 中间处理使用 Float32。不能称为完整 RAW、ICC 广色域、16/32-bit 专业调色或原图像素瓦片编辑器。1:1 按钮明确是预览像素与 CSS 像素的关系。
- 支持手动多区域精修、颜色范围、画笔和确定性调色；未接入自动人脸/皮肤/妆容识别、五官重塑、身体形变、专业修复/克隆、多图层合成和视频直播处理。
- 语音为先录音、明确发送、短语音识别、确认文字再进入创作；不是低延迟全双工实时语音会话。
- 独立的 54 个通用逻辑动效角色和 6 个编辑器角色有尺寸档参数；逻辑角色可被多个 DOM 实例复用，不声称每个 DOM 节点都存在独创曲线或完整退出状态机。减少动态偏好有降级。
- 没有使用真实供应商生产密钥、授权手机号、JMS 节点参数或大陆三网设备。因此短信实收、收费 AI/ASR/审核账单、代理稳定性、真实麦克风、线上支付、生产备份恢复都未实测。
- 67,108,864 像素 / 16384 单边是显式算法预算；实际包含 20MP 输入的小裁切测试，不代表整幅 64MP 能在所有手机高性能导出。
- 自动化通过不构成生产安全保证。生产需补真实账户、小额账单、域名 HTTPS、备份恢复、权限运维和目标用户网络验收。
