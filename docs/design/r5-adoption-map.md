## 采用原则

1. 先对应真实功能，再选择构图、状态和动效。每个组合都说明交互主体及成功/等待/错误/返回的路径。
2. 作品、画布、候选结果是主要视觉内容。放大真实内容、增加留白和不对称比例；不能用重复图片填充空白。
3. 手动选择不会被滚动或自动计时覆盖。页面保留原生滚动；狭窄屏幕不能依赖悬停。
4. 动效分层进入，不延迟输入响应、参数数值、真实画布更新和保存回执。
5. 一种稳定 SVG 语义对应一种动作；同动作跨页面可复用，不同功能不共用模糊图形。
6. 加载骨架匹配当前组件几何，随后进入真实内容、空态或可恢复错误。不让“空态+骨架+旧错误”同时出现。
7. 减少动效、键盘、焦点返回、触摸命中区和响应尺寸都需要真实验收，不能从源码存在推断已通过。

## 不直接采用的机制及理由

- React Bits ScrollStack 默认 smooth 内滚动曾不能正常前进；关闭后原生滚动可见四卡。产品保留原生滚动。
- Card Swap 只借鉴前后层次与可逆选择，不让自动轮播抢走当前作品或用户阅读阶段。
- Chroma Grid 不用于默认灰化用户作品；玻璃折射只用于轻量工具表面，不遮挡画布/数值。
- Grid Motion 只借鉴错列构图，不在作品列表循环重复照片或自动平移。
- Orb/Center Stage 等依赖 GPU 的候选在当前环境未成功渲染，不计为已验证采用。
- 不复制 Aceternity 的付费源码，也不把展示模板里的假数据/假连接写成真实产品功能。
- Lapa 的静态截图观察不等于已操作原站。无法恢复确切原站路径的结论只保留为布局方向。
- Uiverse 35条记录与 React Bits 16动画候选分开计数；不得混淆来源。
- 没有专门验证的组件或预设不得标“已深入体验”。
