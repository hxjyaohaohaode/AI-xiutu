## 新上游契约与不能覆盖的证据

- `496bed2` 的普通 SDR JPEG 母版：配置原生运行时后，支持到 64MP 的 scene-linear-v1 七项全局调色与显式色调映射；真实 RGB16 TIFF 由 worker 解码并按原像素调色后生成显示密度所需栅格。V4 其他工具仍受自己的预算限制。
- `9df0e9c` 的 1:1：按物理屏幕像素而非 CSS 像素计算，图像原点对齐设备像素网格；不能把 CSS 放大或代理图冒称原像素。它只改母版查看器和功能证据，非新增浏览器权限/计费权威。
- RAW、HEIC PQ/HLG、Ultra HDR JPEG 的 signed/float 原片、线性曲线、有序局部仍依各自能力：linear-master、source-normalized、局部上限 8、expectedSourceSha256、expectedVersion；全图 Ultra HDR 与仅裁切能力不可混称。
- 原片 preview 的 fitRegion 与 region 互斥，输入预算/源坐标/ACL/并发受服务端限制；原像素视口、CPU 已验证源带缓存、GPU 适屏和精细 alpha 不由 UI 重排放宽。
- canonical 所列 Windows Edge、Intel Arc、实拍 RAW/HDR/JPEG、物理 DPR/像素对照和 PostgreSQL 结果属于各次上游实测。当前前端截图与 Chrome/SwiftShader 不补充、替代或升级这些性能/硬件结论。
