# 工作台交互修订与验收边界 · 2026-11-11

基于 main `524f65e` 的前端修订。此文档记录本轮实际代码、已执行检查和待 CI 执行的浏览器断言，不将静态检查写成视觉验收。

## 交互与状态所有权

- **工具返回**：首次进入工具也有“返回工具总览”；工具间的上一层可返回。总览支持本地搜索、方向键、Home / End，保留当前配方、图片与参数面板实例。
- **同图上下文**：调整、AI 助手、协作、记录在当前画布内切换。访问过的工具、AI 和协作 owner 保留，退出面板立即 inert；键盘切换后焦点进入可见面板的对应按钮。只有用户点击“在完整页面查看协作”才进入完整页面。
- **协作草稿**：面板与完整页面共用同一个 CollaborateView；意见、任务草稿和筛选状态不因布局改变而重建。完整页面提供“继续精修”。草稿输入与切换均不调用提交 API。
- **AI 内部任务**：LiveAssistant 首次访问后保留实例；切换到生图时 hidden / inert，并接收 visible=false。它原有的 prompt / mode / conversation 卸载缓存只覆盖三个字段，本轮同时保住未确认偏好等组件局部状态。未访问助手的未知生图请求恢复不会提前挂载助手。原请求冻结、任务切换禁用、未知结果核对与活动上报守卫保留。
- **云状态**：提示可收起；顶栏连接图标可重新展开。收起和展开不请求 API；“重试”只沿既有配置、会话与项目读取流程恢复，不触发生成或支付重试。
- **记录**：展示具体参数旧值 → 新值，包含符号与单位；展开时比较局部作用范围、旋转/形状/坐标、曲线点与插值、图层顺序、修复/肤质参数、液化笔画和四角投影。JSON 对象键顺序不算修改。长路径每次显示最多 6 个变动控制点、8 条变动笔画及剩余数量，避免生成巨量 DOM；不会改写或归一化配方。
- **信息密度**：作品和对比以实际作品/项目名为标题；人物识别的通用说明归入按需帮助，保留真实禁用原因、旧图失效、缺少模型输出和容量错误。

## 参考与布局适配

参考来源由本轮独立研究实际操作，并查阅 React Bits 源码快照 `9d9c687`：

| 参考                                                                | 对应实现                                                                                       |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [Animated List](https://www.reactbits.dev/components/animated-list) | 工具总览逐项进入、键盘定位；45ms 分段，上限 225ms，260ms 结束。只在工具总览入场使用 2px 模糊。 |
| [Rubber Segment](https://www.reactbits.dev/micro/rubber-segment)    | 四个固定尺寸上下文按钮，选中背景左右边缘以 180/270ms 和 35ms 差值移动；实际选择立即生效。      |
| [Dock](https://www.reactbits.dev/components/dock)                   | 桌面图标仅小幅上提和 1.12 倍放大；手机固定命中区，不跟随指针放大。                             |
| [Refine Frame](https://www.reactbits.dev/micro/refine-frame)        | 加载区域沿最终内容结构占位；失败保留明确恢复入口，不用定时器模拟完成。                         |

工作台顶栏桌面 54px、触摸/窄屏 50px。手机上下文按钮 44px、底部工具至少 48px；既有 safe-area 和测量得到的面板/画布排除范围继续生效。布局、面板浮动与尺寸持久化协议不变。

按页面区分作品网格、对比双图、协作讨论/任务、文档、交付、用量、搜索、媒体、账号与助手骨架。占位结构 aria-hidden，外层只报告一个加载状态。降低动态效果偏好关闭本轮过渡、逐项动画和悬停放大。精修照片、正在输入的数值与实时操作面板不使用新增模糊。
