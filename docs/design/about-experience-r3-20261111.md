## 各自的运动规则

- **章节选择**：特征章悬停 140ms，Agent 悬停 150ms；点击、聚焦会取消尚未执行的悬停。特征章手动选择后需要累计 64px 滚动才交回滚动控制，Agent 为 80px；滚动边界另设 0.04/0.05 的迟滞，避免微小回滚反复闪动。
- **阅读与焦点**：键盘在章节控制上时暂停滚动接管；短屏不保留空白的 sticky 跑道。手机 Agent 候选按钮至少 44px；最终确认有独立底部空间，小屏画布增高，避免候选压住确认。
- **分组进入**：标题、说明、媒体与标注分层进入，基础 520ms，组内错峰 55ms，总延迟封顶 260ms，位移约 14px；模糊仅用于短暂宣传层，精修像素和输入值不加此效果。
- **指针装饰**：保留系统指针，只在独立背景区域画细线；限制绘制分辨率，静止、离屏、隐藏标签暂停；减弱动态偏好下使用静态结果。
- **对比边界**：真实值立即更新；装饰性弹簧使用刚度 440、阻尼 36、最大弯曲 28px，并以 1/240s 子步长积分；8 个低密度粒子只在运动时出现。无按压时支持指针预览，实际拖动仍由原生 range 控件处理。
- **加载与恢复**：图片各自固定比例、懒加载、骨架与失败重试；渲染独立标记 busy；减弱动态偏好关闭装饰过渡，保持控制功能。

对比弯曲效果来自对公开 Aceternity Compare Slider 的实际观察，是独立实现；其付费 Code 未读取。React Bits 的 Stepper、Animated Content、Fade Content、Voice Pill、Refine Frame 等提供具体状态与节奏参考。免费目录没有通用账本图表，不能把本项目用量图说成直接复制了其中某张图。

### 手机边界与触摸补验

第六轮 `e699d8b` 的 [Account lifecycle 42999900552](https://github.com/hxjyaohaohaode/AI-xiutu/actions/runs/42999900552) 中，正常与减弱动态各 23 项全部通过，包含三语、预设像素、四阶段手机边界、FAQ、注册、两种登录、密码重置与会话撤销。320px 与 390px 的最终确认截图已复核：两张候选及其完整文字、确认区均位于卡片内。隐藏工具的入场位移限制为 `min(25px, 12%)`，小于其右侧空间；卡片用 `overflow: clip`，不会被聚焦操作内部横移。

独立复核随后发现大屏触摸设备点选步骤后只靠 `wheel` 解锁会停留在手动步骤。本提交补充真实触摸/笔意图：单指纵移达到 8px 且大于横移，随后页面实际滚动达到 80px，才交回滚动控制。普通点按、焦点滚动、横向手势及多指操作不解锁；惯性滑动可继续完成阈值，手势在 `scrollend` 或 200ms 无滚动后清理。笔被浏览器接管时，以接管后的页面位置为新基线。所有监听保持 passive，未拦截原生滚动；新的 1024×1366 原生触摸检查记录实际 tap、页面位移和阶段结果，仍以当前 PR checks 为准。

账户测试使用隔离 PostgreSQL、真实 API 和应用，短信出口为内存适配器。支付和自助注销尚未由当前后端开放，因此只验证未开放状态及能力边界，不把它们记作真实付款、注销或注销后重新注册成功。
