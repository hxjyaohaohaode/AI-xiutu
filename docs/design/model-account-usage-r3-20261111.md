## 参数合同与官方核对

先核对 `packages/multimodal/OPENAI.md`、`openai.ts`、公共模型目录、前端 `capabilities.ts`；再实际打开官方 [Images 创建接口](https://developers.openai.com/api/reference/resources/images/methods/generate?site_locale=en)、[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)、[GPT Image 2.6 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst) 与 [Flare](https://developers.openai.com/api/docs/models/gpt-image-2.6-flare)。前端仍以服务端返回的启用目录、运行能力和预算交集为准。

- 模型显示服务端配置名，并在选中控件下保留精确 ID；不根据营销名称猜测 API ID。
- 质量档位直接使用当前模型的能力矩阵。模型不支持的 `complexity` 不生成控件；支持时显示为「规划投入」。
- 主界面保留画幅、质量、输出数量。背景、编码、规划投入、编码质量放入「更多参数」；尺寸、协议边界与未开放项目进入「模型详情」。
- JPEG 与透明背景的约束继续有效。压缩仅在返回能力支持的 JPEG / WebP 格式下出现。
- 数量上限保持应用目录与预算限制，不能因为官方接受 1–10 张就把本地默认 4 张改为 10。
- GPT Image 2.6 的本应用保守尺寸限额不声明为 OpenAI 官方最大值。
- 官方已公开但本后端未实现的 SVG / GIF / 流式 / 渐进预览没有变成可提交参数。
- 未确认任务的原始请求、报价、输入冻结与禁止重发保护保持原实现。

## 具体交互

### 账号

默认表单仍为密码登录，显式给出「登录已有账号」与「创建新账号」。点击当前登录方式不清空已填写内容；点击登录大类也不把短信登录强制切回密码。

注册详情的页头返回先退到手机号步骤。已经获取验证码后，再前进直接继续填写；不因返回操作再次发短信。注册/重置从首层返回登录，登录从来源返回创作或首页。模式真正改变时仍清理密码和验证码。原操作门禁、未知回执、冷却时间与会话权属保持。

认证图片使用本轮独立生成的 `/about/auth-atelier.webp`，不复用调色样图。页头从 88 px 降到 64 px，手机从 76 px 降到 56 px。

### 模型设置

「任务设置」「助手设置」为命名 `section`（可访问性 region），带「返回对话」按钮。设置与对话仍属于同一个 AI owner。设置关闭保持挂载且 `hidden/inert`；浮层监听所有祖先的 `hidden/inert/open`，避免原生 popover 漏在关闭的面板外。

常用设置单元保留 44 px 触摸高度，键盘可以直接切换，动画不阻塞提交。手机数值输入为 16 px，避免聚焦放大。

### 用量

主图支持悬停、触摸横拖、前后按钮、方向键、Home / End。读数固定区域显示所选真实日期与金额，曲线不使用曲线拟合制造极值。日期按上海计费日历与 API 排他结束边界排布；未记录日期及未知金额处断线；负向调整保留方向。

账本表格、分页快照、空间/成员过滤、完整钱包余额说明、未知金额、CSV、独立预占/结算/释放/到期关系保持。数字动画只有实际数字轻移入，金融值没有虚构中间数。

应用首次进入、用量接口、容量接口、报价接口、AI 懒加载分别显示贴合内容的骨架。减弱动态偏好下关闭这些动画。
