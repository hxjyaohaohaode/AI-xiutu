## 8. 后端对齐边界

- main 已加入 schema20 的 immutable media_grade_revisions、native working buffer、16.8MP/8192 预算、MediaSourceViewer/useMasterPreview、16-bit / scene-linear 原图路径。
- 不回退到旧低分辨率交互策略；不碰 renderWorker、point-preview、histogram 等引擎算法。
- 保留不可变原图、source identity/hash、revision/expectedVersion、CAS、角色 ACL、协作 lease 和来源复制限制。
- 模型、参数与价格取供应商 descriptor ∩ 服务端 Ops 配置 ∩ 当前 operation；不能只靠模型名字猜合法组合。同一 modelId 的能力变化也需重新校验未提交草稿，已在执行的请求保持冻结参数。
- 当前产品未开放的流式图像、SVG/GIF、partial/input_fidelity 等供应商能力不添加 UI；compression 仅 JPEG/WebP、transparent 仅 PNG/WebP、mask/markup 互斥且绑定首 reference，后端继续核验尺寸/alpha/ACL。
- BOS 审计后端字段为 targetType/targetId/detail，部分前端使用 entityId/details；恢复时先验证实际类型并在边界归一化。
- Quota 写回先采纳 POST mutation 回执；后续 GET 失败应显示已保存但刷新失败，只提供刷新动作，不重发 mutation。
- Logo 文件读取/转换用独立 generation owner，只更新对应字段；不能以旧 config 闭包覆盖新表单。
- 已知静态风险：catalog 只在 mount 刷新；辅助图片 MIME/尺寸/预算前检不足；BOS logo 上传的异步 config owner；Quota 写成功后再次 GET 失败可能误报为写失败；现有 image PUT version 自增但未有 expectedVersion，不能由 UI 假装有 CAS。
- 未决计费请求不自动重发。语音终态/账本以真实回执为准。
- 自助账号注销与重新注册、真实支付没有契约时必须保持不可用，不创造测试专用成功界面。
