# 官网交互研究与本轮实现

日期：2026-11-11。以下是本轮连接浏览器中实际检查的页面与操作，不表示遍历了每个站点的全部页面、登录区或付费内容。研究的是布局和交互原则，未复制官网源码、品牌或素材。

## Aceternity 组件检查

检查用户原有的 [Components](https://ui.aceternity.com/components) 标签页，进入 [Compare Slider](https://ui.aceternity.com/interactions/compare-slider)。观察原生 slider、公开参数、预览/代码层级，并用方向键实际操作对比分界、截图确认两侧画面。未获取付费源码。

映间比较演示独立实现，前后图像来自同一素材和项目真实修图引擎，原生 range 支持键盘控制。不使用会干扰照片判断的色散、粒子和拖动模糊；分界、图像位置和尺寸保持稳定。

其他十个参考站见 [组件研究](component-study-20261111.md) 与 [画廊研究](gallery-study-20261111.md)。这三份记录覆盖原浏览器中的十一站和指定的五个官网。Mobbin 的 403、部分素材失败与空白预览均保留记录，不计为已完成的内部交互研究。

## About 独立设计

- 首屏是一张真正可编辑的图像：色温、曝光、自然/鲜明/柔和以及原始/调整对比。专用 Worker 调用 `renderRecipeV4`，最多处理 400,000 像素。它不是 CSS 滤镜演示。
- `about/sample.ts` 为演示与工作台提供唯一参数映射；继续编辑携带原图和配方，保留非破坏编辑能力。
- 初次打开介绍不加载整个编辑器；首次进入工作台有独立骨架与重试状态。返回介绍不会卸载已有作品。
- 非对称首屏、可切换工具说明、工作空间构图、FAQ 和结尾动作各自处理布局。没有虚构评价、客户、用户数量或服务能力。
- 橙色马蹄莲、浅蓝灰墙面与自然斜光素材由本轮生成并压缩为 `public/about/color-study.webp`；界面明确标注 AI 生成素材，它不是产品截图或外站素材。
- 三种语言分别处理标题与按钮；繁体界面使用一致的儲存、匯出、專案、本機等词汇。用户内容不进入翻译流程。

## 动效与几何

| 部位     | 独立处理                                                                               |
| -------- | -------------------------------------------------------------------------------------- |
| 指针响应 | rAF 合并输入；线条最大位移约 9px、图像约 1.5px；离开恢复；触屏/减少动态效果不启用。    |
| 预览计算 | 单个在途 Worker 任务，连续输入只保留最新待处理值，过时画面不落地；离开终止 Worker。    |
| 功能说明 | 竖向键盘标签、独立插图与激活区域进入动效。                                             |
| FAQ      | 原位高度/透明度过渡；收起内容 inert/aria-hidden。                                      |
| 工具栏   | 按真实文字宽度测量选中背景；语言变化重新测量；键盘绕过滚动箭头。                       |
| 浮动面板 | 位移与尺寸变化参与时长；停靠方向对应变换原点；拖动即时响应。                           |
| 命令菜单 | 键盘与指针选择分开处理，结果滚动限定在菜单内部。                                       |
| 账号弹层 | 表单单独设计内容层级；共享模态容器统一管理手机全宽底部面板和安全区，避免重复宽度覆盖。 |

组件复用焦点、关闭和手势基础设施，具体尺寸、布局与动效按使用位置设定。验证见 [验收记录](../verification/frontend-experience-20261111.md)。
