## 本次修改

共享脚本 `scripts/ci/prepare-apt-mirror.py` 只在 GitHub Actions 的 Linux / Ubuntu runner 生效。每次 `getent ahosts` 最多等待 10 秒：Azure 可解析时不读写任何源文件；Azure 失败、官方 `archive.ubuntu.com` 可解析时，才绕过精确匹配的 Azure `/ubuntu` 源。两个域名均失败则非零退出，源文件保持原样。

- 现代 `apt-mirrors.txt` 已有官方 archive 时，仅移除 Azure 项；没有官方项时，仅替换 Azure URI，保留每行 metadata。
- 兼容旧 `sources.list`、`sources.list.d/*.list` 和 deb822 `*.sources`，只修改来源 URI；保留 `Signed-By`、security 源、第三方源、注释、换行和文件权限。
- Baseline 的 browser / OCR、Account、AI 四个 job 均在 APT 依赖安装前调用。Account / AI 的路径触发包含该脚本；Baseline 原本检查所有变更。

没有修改 DNS、代理、认证、依赖清单、测试门禁或超时。
