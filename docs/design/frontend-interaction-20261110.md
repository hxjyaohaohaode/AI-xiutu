## 本轮目标

- 手机优先的画布、上下文面板与 AI composer，避免多层工具同时占据首屏。
- 全局浅色/深色语义色，覆盖页面、弹层、原生控件、状态和悬浮区域。
- 按操作语义重新组织 SVG、文字与容器比例；删除空泛标语。
- 输入即时反馈；进入、退出、展开、切换具有可中断的位移和透明度变化，保留减少动态偏好。
- 最新接口能力映射，保留请求身份、权限、不可变版本、草稿和计费恢复语义。
- 各状态在桌面、平板、窄手机、短横屏实际浏览器检查，完成 GitHub 验证后合并主线。

### 移动 AI：输入持续可达，设置按需出现

AI 的 DOM 顺序就是“会话工具栏 → 对话内容 → 输入区”，不再使用 CSS `order` 把读屏顺序与视觉顺序倒置。常规面板只有消息主体滚动，输入区位于底部；长草稿在输入框内滚动。默认文字模式，实时语音由用户主动进入；生图等任务保留自己的规格与真实能力校验。实现分别位于 [AIPanel](../../apps/web/src/components/AIPanel.tsx) 和 [LiveAssistant](../../apps/web/src/ai/LiveAssistant.tsx)。

设置与会话记录复用受控 `Modal`，保留需要保存草稿的子树。关闭设置不会清空尚未发送的要求；切换到其他工作视图时关闭覆盖弹层，活动请求或通话仍保持挂载。顶部活动条按真实连接、通话、静音和结束状态展示，并提供返回 AI、静音及结束入口，避免“收起界面”暗中变成“挂断”。迟到结果继续检查当前作品、版本和脏草稿，不能因为请求完成就强行离开正在编辑的文档。相关接线见 [App](../../apps/web/src/App.tsx)。

手机 AI 面板以 224px、其他布局以 260px 作为建议最小高度，并服从实际工作区上限；显式折叠仍是独立状态。短面板优先减少装饰、说明和垂直留白，输入保留 36px 高度，手机发送等主要操作保留 40px 触达尺寸。可用空间进一步小于控件总高度时，启用面板纵向滚动，保证操作仍有到达路径。活动通话在不超过 360px 高的面板中使用单一纵向滚动，并让静音、打断和挂断吸附在上方；保留模型、附件、输入和费用信息。700–759px 的简化标题栏也保留内部关闭入口。实际浏览器的尺寸、裁切与命中证据见 [本轮验收记录](../verification/frontend-interaction-20261110.md)，物理设备另行记录。实现见 [面板几何](../../apps/web/src/workspace/panelGeometry.ts) 与 [AI 响应式样式](../../apps/web/src/ai/composer.css)。

### 主题、功能图标与动效的共同规则

浅色、深色、跟随系统属于全局外观偏好；`html[data-theme]` 下的语义变量同时驱动页面、工具、状态、弹层和原生控件。浅色使用暖白表面、深色文字与琥珀强调色，深色使用分层深灰绿表面和对应的可读文字。照片像素、画笔颜色及通道数据不受 UI 主题改写。偏好与布局分开保存，并响应系统及同源标签页变化，见 [useStudioTheme](../../apps/web/src/workspace/useStudioTheme.ts)。

功能图形不再共用一个泛化装饰符号：曝光采用光照、曲线采用坐标曲线、构图采用裁切、版本采用历史、协作采用成员、交付采用包裹等语义；导航使用统一 24px 网格的 [StudioGlyph](../../apps/web/src/components/StudioGlyph.tsx)，AI 与账单等细分操作使用对应 SVG 图标。图标旁的名称或可访问标签提供明确含义，状态仍保留文字，不能仅靠颜色区分。

弹窗、下拉、折叠和视图切换共享 `Modal`、`ChoiceSelect`、`MotionDetails`、`MotionDisclosure` 和 `MotionSwitch`。退出内容立即变为不可交互，必要时继续保留子树以完成退场或保存草稿；重复确认、异步关闭与卸载取消由共享关闭逻辑处理。焦点回到真实触发入口，业务确认后的账号 / 作品 / 草稿校验仍由原操作负责。动效表达“打开了哪里、关闭了什么”，不承担网络成功、授权成立或请求完成的含义。
