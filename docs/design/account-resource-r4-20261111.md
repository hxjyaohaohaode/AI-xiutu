本记录覆盖真实账号入口、作品库、跨空间素材检索、版本对比加载与用量图表。About、BOS、模型选择及精修面板由同轮其他工作区负责。后端行为继续以 API、共享 contracts 和服务端授权为准；本区没有修改后端，没有新增假接口、演示账号或演示用量。

## 先确认正在使用的界面

`App.tsx` 当前实际作品入口使用 `AssetLibrary.tsx`，跨空间检索使用 `ResourceSearch.tsx`。`WorkspaceViews.tsx` 中旧的 `WorksView` 主要仍由历史测试引用，不是当前作品库的实际入口。因此本轮作品密度调整落在真实 `AssetLibrary`，没有把优化停留在旧组件上。`WorkspaceViews.tsx` 仅改变 `CompareView` 初次读取版本时的骨架。

登录入口本来已经以密码登录为默认模式，登录与注册有明确入口；注册分为手机号、账号设置两步，重置可以回到登录。它们已有前进、后退、焦点与请求未知状态。本轮保留这些行为，没有重写已经与短信、身份恢复绑定的状态机。账号接口与尚未实现的生命周期能力继续见 [账号契约](./account-contract-20261110.md)。

## 账号产品展示的真实性

使用已经存在的 `/about/workspace-zh-CN.webp`、`workspace-zh-TW.webp`、`workspace-en.webp`，按当前语言选取。它们是已有真实工作台捕获，不是本轮新截图。截图里的画布、调色与工具均来自实际产品。

旧捕获的顶部包含旧品牌色与当时的云端离线横条，因此账号版式仅裁切外层顶栏，保留完整编辑内容区域；原始图片文件不变。外框的标志来自本轮统一 `BrandMark`，不会再带入旧捕获的品牌色。截图是功能预览，不扮演可操作编辑器，也不显示虚构的当前用户数据。

图片加载时保留尺寸，失败时显示文本及重新载入按钮。侧栏在窄屏隐藏，让账号表单先完成任务；账户路径、字段、按钮与返回不会因为图片失败而不可用。各语言都有预览替代文本，功能标注使用列表语义。

## 资源与授权边界

原图缩略图只请求服务端返回的 `thumbnailUrl`，或已实现的 `GET /v1/assets/:id/thumbnail`。不因没有缩略图就解码整张原图，也不以别的照片替代失败图片。该接口的尺寸、缓存与 ACL 契约见 [API 文档](../../apps/api/API.md)；前端没有另造缓存授权。

资源查询继续使用现有 `resourceQuery` 与当前后端资源端点。查询改变时中断旧观察，generation 阻止旧回包覆盖新范围。可访问空间的 ID、种类或角色变化时重新读取资源，并关闭原范围的标注 / 原件弹层；旧素材不被当作新范围的结果保留。

长期标注仍归当前账号所有，保存 / 删除继续带 `expectedVersion`。短隐私提示留在表单中，更长的访问权、AI 引用边界放在展开说明里。只有用户明确引用时才进入 AI 参考；标注不授予已经撤销的原素材权限。关闭确认只处理本地未保存编辑，不改变后端 CAS、权限或删除规则。

保存作品按钮继续调用真实 `onOpen(work)`，原图按钮继续调用 `onOpenAsset(asset)`。没有把原图封面伪称为保存作品的最终渲染，也没有自动把宣传图片导入用户项目。

## 用量图表的数据与操作语义

预占、结算、释放、到期是四类独立流水，使用相同纵向数值尺度，并列比较；它们不能相加作为余额。本轮没有改变权益、单价或账本数据源。

每条图表同时区分两种数值：标题附近是已记录合计，下方是当前选中日期的精确值。缺金额不补 0；可访问名称保留“已记录合计”和未知日期数量。屏幕阅读器可以获知选中日期与实际有符号数值，也可以展开实际数据表。

鼠标查看、触摸定位、方向键、Home、End 与 Escape 使用同一个日期选择；四条图表共同响应。日期轴使用报表的完整上海时区范围，不把首末已有记录挤成整个报表周期。读取不到某一天不会连线假定它的变化，月度桶按月序相邻判断。输入序列排序只操作副本，不改变原报表。

主趋势图增加稳定占位的“回到最新”按钮；日期快捷范围增加准确的按下状态。切换记录时按钮位置不因出现 / 消失而移动。

## 动效、触达与响应式

- 主要操作保持至少 44px 高度，详情在移动端同样具备可点击的展开行；搜索、项目与筛选按钮在窄屏有明确换行顺序。
- 原图图像不做高斯模糊，不为了进入动效降低编辑内容辨识度。轻微模糊只用于账户说明文字的阶段进入。
- 资源卡片的错峰限制在短时间内，不以列表长度线性延长等待。
- 缩略图、账号侧栏、资源卡片与流水导航均尊重 `prefers-reduced-motion`。关闭动画不会关闭按钮或键盘路径。
- React Bits 的现场查看与组件对应表由本轮统一参考报告记录。本区使用现有 motion 基础设施实现适合操作型界面的阶段进入、展开与状态过渡，没有声称本区独立完成了参考网站的浏览器验收。

## 后续契约与明确限制

现有后端尚未提供公开购买 / 订阅 / 退款以及自助注销 / 注销后重新注册接口。本轮账号中心继续显示真实服务能力，不显示假的成功结果或可以点击但没有后端的付款按钮。新能力必须与后端共同定义，再通过权威 capability 接入；具体清单见 [账号契约](./account-contract-20261110.md) 与同轮 [前后端对齐](./frontend-api-alignment-r4-20261111.md)。
