# 前端 R4：逐项验收清单

日期：2026-11-11。基线：`e376eb8`；工作分支：`frontend/experience-r4-20261111`。

本记录汇总本轮实现、自动测试和主任务实际完成的浏览器操作。**代码实现、自动回归、本机浏览器操作、带真实账号的云端业务验收分别记录。** 21 张产品截图已经落盘；About、账号入口和本地编辑的下列动作已经实测。资源、用量、运营、语音与付费模型的真实账号浏览器场景仍待验证，不能据此写成“全站全部通过”。GitHub CI 的最终结果另行登记。

## 1. 状态与证据规则

| 标记 | 含义 |
| --- | --- |
| 代码已核 | 当前分支存在对应实现与状态处理；不单独证明布局或真实服务成功 |
| 自动回归通过 | 已实际执行的类型检查或测试；具体命令、数量、跳过项与先后范围见第 6 节 |
| 本机浏览器实测 | 主任务通过 CUA 实际操作运行中的前端，按第 3 节所列动作和视口确认结果 |
| 待 CI / 浏览器回归 | 功能已经实现，但对应组合、错误注入或受控集成浏览器场景尚未执行；不表示产品没有该功能 |
| 待真实账号 / 服务验收 | 需要合法账号、授权项目、媒体权限或实际服务；源码和测试夹具不代替该验收 |
| 既有产品契约缺口 | 当前接口尚未提供完整能力；与“已有功能尚未验收”分开，见第 5 节 |
| 环境限制 | 缺少运行能力或可选依赖，明确记录失败 / 跳过，不伪造成功 |

“保留并复核”表示基线已有能力，本轮检查或补强，不计作从零新增。代码没有名为 `BOS` / `Boss` 的独立路由或组件；本轮将 `OpsDashboard` 的相关问题一并修复，但不将这一推断写成用户口述名称已被确认。
