# 前端 R4：模型、对话与工作节点对接

核对日期：2026-11-11。基线：`e376eb8`。本轮修改浏览器呈现、选择联动及研究事件合并，没有更改 API、数据库、模型目录、收费状态机或供应商适配器。

## 本轮实际修改

| 用户指出的问题                   | 当前改动                                                                                                                  | 数据依据                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 云端对话像草稿，长消息难以阅读   | 助手回复与生成文案支持段落、短标题、列表、引用、代码、简单表格和显式网页链接；回复可以复制；用户输入继续保持原文字        | 原始 `message.text` / 文案 `body`，复制仍使用原文字，不向模型补造内容 |
| 工作节点像装饰，状态和关系看不清 | 任务节点显示实际执行类型、完成/失败/中断/待同步、证据数量；点开查看真实依赖；汇合保留独立状态                             | `branch.changed` 与 `GET /v1/assistant-turns/:id/branches`            |
| 模型选择信息重复、参数不直观     | 保留服务端显示名，精确模型 ID 收入可展开信息；输出画幅随真实宽高联动；参数名称与可访问名称保持一致                        | `/v1/models`、`/v1/assistant/models` 返回值                           |
| 参数联动不完整                   | 选择 JPEG 时在能力允许范围内联动到不透明/自动背景；选择透明背景时联动到 PNG 或 WebP，并给一次明确反馈；无兼容组合时不可选 | 当前模型 `parameterCapabilities`，不按 ID 猜测                        |
| 工作卡片全部堆成文字和假缩略图   | 执行额度按实际授权分为服务点与操作次数；参数表强调真实建议值；参考图加载失败显示失败状态，使用真实受保护缩略图            | `AssistantGrant`、`AssistantCandidate`、工作区白名单 spec             |

研究快照与事件现在按节点 ID 合并：运行中的稀疏事件覆盖同节点快照，但不会删掉已知依赖；结束后读到的权威快照覆盖旧流式状态。尚未同步的 running 节点显示“待同步”，不会因为前端请求结束就假定已完成。显示的“已完成 / 当前节点数”仅统计已收到的节点，不作为耗时百分比或账务依据。

## 当前契约的对接规则

| 环节               | 前端依赖                                                                                | 必须保留的语义                                                                                            |
| ------------------ | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 图片模型列表       | `models[].id/label/enabled/runtimeAvailable/runtimeOperations` 与 `availableOperations` | 运营登记、运行时配置与账户真实外部验收是不同事实；前端不自己开放新模型                                    |
| 图片参数           | `parameterCapabilities`、模型尺寸边界、`batchLimits`、`pricing`                         | 以返回的交集为准；尺寸、每批像素、输出数量和质量费用一起验证                                              |
| 图片提交           | `imageOptions.quality/background/outputFormat/outputCompression/n/complexity`           | 只有当前模型支持的字段进入请求；PNG 不发送压缩参数；未知结果不自动重发                                    |
| 文本助手与连续语音 | 独立 `/assistant/models` 配置、模型能力、作用域与授权                                   | 不把图像模型配置当作对话/语音配置，不通过呈现切换新增授权                                                 |
| 消息流             | 既有轮次与持久事件 ID                                                                   | 同一消息保持原组件 owner；没有逐 token 重播入场动画；格式化不执行 HTML、脚本、远程图片或模型生成的任意 UI |
| 工作节点           | `id/parentId/dependsOn/kind/state/execution/resultCount`                                | 保留真实分支身份与状态；不添加假任务、假数量、计时或百分比                                                |
| 候选采纳           | 既有候选 ID、决定、基准版本与完整本地配方身份                                           | 保留预览确认、建议模式限制、租约和版本检查；工作卡片不能绕过同一个 `onDecision`                           |

代码入口：`apps/web/src/ai/{ModelChoice,ImageParameters,AssistantText,ResearchGraph,WorkspaceCards}.tsx`；纯状态处理：`capabilities.ts`、`message-format.ts`、`research-graph-model.ts`。消息格式是有意受限的可读文本格式，并非完整 Markdown/MDX 渲染器。不能识别的格式保留为文字；表格过宽时在消息内部滚动。

## 官方 OpenAI 资料核对

本轮重新打开了[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)、[生成接口](https://developers.openai.com/api/reference/resources/images/methods/generate)，并逐项对照仓库的 [OpenAI 能力矩阵](../../packages/multimodal/OPENAI.md) 及 [API.md](../../apps/api/API.md)。

- 2.5 / 2.6 的质量选项包含 `xhigh/max`，不能据此给较早模型添加这两档；图像规划 `complexity` 与渲染质量是两个参数。
- 透明背景需要支持透明度的格式；JPEG 不能承载透明度。压缩字段只适用于 JPEG / WebP。
- 官方文档公开 GIF / SVG 等选项，不等于当前应用已完成这些生成结果的安全处理、逐帧审核、存储与账务链。仓库仍显式返回未开放；本轮没有把这些开关改为可执行。
- 当前应用对 2.6 的尺寸采取已发布契约中的保守限制。前端不拿官方模型最大值覆盖服务端预算。

供应商公开能力、应用适配器、运营配置与实际账号权限分别判断。没有调用付费模型，也没有修改服务点价格。

## 需要与后端同步的既有边界

以下均为当前仓库已经记录、此次呈现改造没有伪造完成的接口缺口；后端更新时应在同一 PR 中补前端读取与回归。

| 边界                  | 当前表现                                                      | 后续需要的契约                                                                              |
| --------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 普通 AI 历史恢复      | 完整结果仍从项目最近 100 条任务中定位                         | 按已知任务 ID 读取完整候选结果，或稳定游标分页                                              |
| 个人/团队语音未知结果 | 保留原请求与保守阻止新拨号，不通过清空本机记录放行            | 原幂等 key → 稳定计费身份、团队邀请 → 计费会话/终态；已知任务只读核验与服务端账号级未决准入 |
| 生图流式与 GIF/SVG    | 模型详情标明未开放，不能发出不支持参数                        | 对应审核、格式安全、预算、持久结果及失败结算一同实现                                        |
| 候选专用 commit       | 现有显式预览后走正常版本化保存，`applied:true` 不重复放入画布 | 如果迁移到专用 commit，需要版本/租约/幂等回执完整接线                                       |
