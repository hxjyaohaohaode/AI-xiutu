# 六个参考图库的实际交互观察 · 2026-11-11

本轮使用独立浏览器标签页查看首页，并真实操作分类、筛选、详情或媒体。以下记录区分网站自身交互、展示截图与录制素材；范围是六站首页及列出的具体页面，不代表穷尽网站全部内容。连接本地浏览器的插件返回缺少 originating browser context，改用当前可用的独立浏览器。没有登录、收藏、订阅、付费或修改账号偏好。

## 对应实现

- `apps/web/src/workspace/ToolDock.tsx`：按按钮实测几何移动选中背景、工具自身参与 roving focus、切换语言后重新测量、溢出滚动动作不混入工具键盘路径。
- `apps/web/src/workspace/CommandMenu.tsx`：输入与列表分区、实测活动背景、键盘/指针所有权、短结果文案与可换行原因。
- `apps/web/src/workspace/FloatingPanel.tsx`：停靠方向、距离/尺寸决定的转场时间、即时拖动、辅助说明折叠、布局菜单关闭时归还焦点。
- `apps/web/src/workspace/WorkspaceNavigation.tsx`：线性工作视图、主题与语言分别设置；当前目的地的选中态可辨。
- `apps/web/src/workspace/StudioWelcome.tsx` 与 `experience.css`：非对称编辑入口、明确导入操作、独立手机排版；按组件设置尺寸、间距、运动、reduced-motion。

这些决定已经落实到上述组件。参考仅用于理解布局和行为，没有下载或复用第三方品牌、截图、字体与视频资产。真实服务动作、后端可用性和付费能力仍以项目接口返回为准。
