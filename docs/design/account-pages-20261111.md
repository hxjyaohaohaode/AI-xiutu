# 独立账号页面与工作台保留

本轮把登录、注册、重置、账号中心和注册完成从弹层改为文档页面。账号协议仍以 [账号契约](account-contract-20261110.md) 为准；页面改造不开放没有服务端实现的支付或注销能力。

## 页面与状态

| 路由         | 可见内容                              | 返回与数据所有者                                                           |
| ------------ | ------------------------------------- | -------------------------------------------------------------------------- |
| `#/login`    | 密码 / 短信登录、结果未知时的会话核对 | 返回打开它的首页或工作台；密码与验证码不写浏览器存储                       |
| `#/register` | 手机号 → 账号设置两步表单             | 第一阶段不声称验证成功，注册 API 最终验证验证码                            |
| `#/reset`    | 重置表单、独立完成状态                | 观察真实 Session；不因重置其他本人号码而认定当前账号已退出                 |
| `#/account`  | 概览、安全、额度、数据与退出          | 与工作台共用同一个 App / Session；未登录时进入真实登录页                   |
| `#/welcome`  | 真实注册回执后的个人空间与下一步      | 仅当前页面实际接收过注册成功的账号显示该完成页；直接访问不制造注册成功状态 |
| `#/usage`    | 工作台中的独立用量视图                | 继续使用真实权限范围与账本接口；离开该视图同步回工作台路由                 |

认证页面内部切换更新 URL。浏览器后退 / 前进恢复相应页面，手机号之外的敏感表单内容不跨重新挂载保留。语言切换仍保留同一个正在填写的表单。

## 布局

桌面认证页采用图像与表单分区；手机优先展示完整表单，用原生文档滚动访问长内容，不再把表单装进底部弹窗。每页都有品牌、返回与语言入口。认证字段为 16px 文字、48px 最小高度，返回等主要导航具有独立点击区域；三种语言由独立文案和现有应用目录共同覆盖。头部与内容区分别计算左右安全区间距，窄屏和短横屏覆盖规则保留这两个方向的安全区值。

账号中心采用更宽的页面内容区，桌面保留侧边栏目；窄屏和短横屏使用可滚动栏目条。懒加载失败在账号页内显示重试，保留原工作台实例。

## 保留与退出保护

- 工作台子树在账号页下设置 `hidden` 与 `inert`，保持同一个编辑器、画布、协作和 AI 实例；隐藏画布不能消费账号页快捷键。
- 认证请求尚未结束时，页面返回、品牌入口和浏览器历史导航不能丢弃该请求的观察者。结果未知状态仍沿用原核对流程，不自动再次提交。
- 认证页面退出后，必要时只读核对当前会话；旧回包、旧 finally 与背景读取不能覆盖新账号所有者。
- 注册完成、导入后的后续操作、账号退出、会话失效分别处理目的页；不会以显示完成页代替真实注册回执。
- 支付、订阅、注销、手机号释放及注销后再注册没有新造接口；作品导出、实际权益和退出仍使用已有能力。
