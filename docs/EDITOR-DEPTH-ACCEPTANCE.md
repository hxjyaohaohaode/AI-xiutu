# 编辑器与人像深化验收

本表承接 [整仓工作清单](BACKEND-DEPTH.md)。本次补充涉及选区、实时调色、液化、人物几何、妆容、光影与素材合成。登记项以正常产品入口、实际像素、反例、旧配方和交叉操作均有证据时勾选。

## 先复现的链路

| 验收项 | 真实操作与检查 |
| --- | --- |
| [ ] 选区能旋转及自由调整 | 用宽图、竖图、旋转裁切图操作中心、旋转柄、两轴和多边形顶点。比较实际作用像素、反选、羽化、分块与服务器回放。回退或取消恢复精确结果。 |
| [ ] 选区提示自动退出 | 首次进入、切换区域或重新查看时提示范围。调整照片时检查画面可见，显式显示与当前工具的状态互不覆盖。 |
| [ ] 调色连续响应 | 桌面鼠标和模拟手机触摸分别检查曝光、曲线、饱和度及局部调色。记录输入、首个变化、松手前的画布帧和最终像素，覆盖同时含修复或变形的配方。 |
| [ ] 液化清晰可控 | 用高频纹理、细发丝、文字、半透明边缘和多人主体实测。比较拖动期间、松手、撤销与导出，检查外部像素、边缘重采样和强度极值。 |
| [ ] 交叉联动 | 同图按多种顺序组合几何、局部、液化、手绘、AI 候选、历史回退和团队提交。检查旧配方、多人冲突、范围穿越、权限撤回、导出一致性。 |
| [ ] 参数边界与最小步长 | 对每个可调项核对参数定义、前端滑块和精确输入、共享配方、API、编辑执行及导出。检查最小值、最小值加一步、零前一步、零、零后一步、最大值减一步、最大值、超界输入、撤销重做。只允许单向的控制记录语义。记录最小步在高位深、8 位取整、源分辨率及多次操作后的实际效果。 |
| [ ] 工具归类与接口一致 | 核对全局、局部、几何、人像、手绘、合成、修复及 AI 的入口与共享参数，识别重复语义与跨区影响。验证多端输入、前后端配方回放、版本与历史兼容。 |
| [ ] 图片题材和输入适配 | 对风景、建筑、花卉、生活、运动、夜景、人像、多人、半透明素材及不同尺寸和方向分别验收。记录高光、暗部、肤色、细边、透明像素和高位深输出，避免将同一套自动提亮用于全部题材。 |
| [ ] Agent 工程与编辑联动 | 从当前画面、来源、历史和确认记忆组装 context。核对 prompt、可用技能和 MCP 工具的发现、权限与协议，测试分支、汇合、候选、像素复核、人工接管、撤销和成本。用协作、生成和语音复用同一执行边界，核对流式状态和断线。 |

## 人像逐项要求

| 部位 | 用户要求 | 当前源码核对与验收目标 |
| --- | --- | --- |
| 皮肤修整 | 祛斑、祛痘、磨皮、祛皱、皮肤肌理、美白、匀肤、祛黑眼圈、肤色、气色提升 | 现有斑点与色斑衰减、导向柔化、高频控制、细纹衰减、肤色明暗/冷暖、匀肤、眼下曝光与气色。斑痘分型、单条皱纹跟踪与修复、黑眼圈分割仍需独立证据。分别检查深浅肤色、相近肤色背景、妆容、反光和保留区域。 |
| 立体与提亮 | 亮眼、五官立体、眉毛增强、面部丰盈、超清 | 现有亮眼、眉部细节和鼻梁局部光影。面颊体积、独立部位照明和清晰修复需查实效果与稳定性。 |
| 轮廓 | 瘦脸、小脸、窄脸、V 脸、太阳穴、颧骨、下颌角、下巴、脸型、下巴长短、尖下巴、祛双下巴、下颌线、头包脸 | 现有脸宽、下半脸、太阳穴、颧骨、下颌角和下巴长短几何。轮廓相近项要以各自控制部位、支撑范围及方向验证，补齐下巴形状与颏颈交界。 |
| 发际与颅顶 | 发际线、蓬松发、颅顶比例 | 现有额头位置只依赖面部点。需要真实头发选区、发根与轮廓条件，检查细发、遮挡、透明边缘及背景保护。 |
| 三庭、头部及视角 | 上庭比例、中庭比例、下庭比例、小头、头部上下位置、左右位置、旋转、面部对称、黄金侧颜 | 额头和姿态头部缩放已有实现。逐区检查角度、尺度、嘴眼鼻联动和遮挡。二维位移与真实转头遮挡的测试分别记录。 |
| 眼部形态 | 眼睛大小、眼距、眼睛旋转、眼间距、眼高、眼宽、眼睑下至、瞳孔大小、内眼角、外眼角、眼尾上扬 | 眼高、眼宽、下眼睑及虹膜各有作用范围和方向。虹膜可见性和范围由关键点及眼轮廓约束。逐项继续核对闭眼、眯眼、侧脸、镜片、睫毛、瞳孔分割及单独眼角。 |
| 鼻部 | 瘦鼻、鼻尖、鼻长、3D 隆鼻、鼻翼、鼻梁、鼻子提升、山根 | 鼻翼、鼻尖、鼻长有局部位移，鼻梁有局部光影。补足山根和鼻梁几何，真实三维与二维单独验收。 |
| 眉形 | 眉毛粗细、眉毛位置、眉毛倾斜、眉峰、眉间距、眉毛长短 | 眉位沿脸部竖轴移动，支持眉部缩放及纹理调整。各控制按眉头、眉峰、眉尾及垂直轴分开核对。 |
| 唇部与表情 | 嘴唇大小、微笑嘴角、3D 丰唇、立体唇、嘴宽度、嘴位置、笑容管理、嘴倾斜、M 唇、丰上唇、丰下唇 | 嘴宽和上下唇各自独立作用，内唇轮廓限制影响范围。继续检查闭口、露齿、口腔、唇纹和原有表情，单独验证三维效果。 |
| 牙齿 | 牙齿矫正、白牙 | 需要口腔内可信牙齿区域、牙龈保护和逐齿条件。核对露齿与不露齿、低光与口红，不把整块口腔提亮视作白牙。 |
| 身体 | 增高、天鹅颈、瘦肩、瘦手臂、瘦腰、美胯、长腿、瘦腿 | 现有姿态约束的身体纵向、颈肩、臂腰胯、腿长和腿围控制。分别验证全身、截断、交叉姿态和背景直线，检查关节可见性条件。 |
| 手动修形 | 手动推脸、瘦脸、瘦身 | 已有液化操作与保护蒙版。测试力度、拖动速度、多个笔触重合、撤销和边界，按新的清晰度要求继续检查。 |
| 妆容 | 口红、卧蚕、手动妆容笔、修容、腮红、睫毛、眼神光、痣、眼线、眼影、美瞳、双眼皮、雀斑 | 已有口红、眼影、腮红、修容、高光、眉妆与卧蚕；绘制工具可手画。其余逐项检查睑缘和虹膜位置、毛发与闭眼约束、笔刷边界以及多款颜色叠加。 |

## 图片编辑逐项要求

| 范围 | 用户要求 | 当前源码核对与验收目标 |
| --- | --- | --- |
| 调色与层次 | 光影、氛围、光感、色彩层次、色调曲线、色温、色调、褪色、透亮感 | 已有分区调色、通道曲线、色温色偏、分级及褪色。分别测暗部、高光、薄雾、混合光和肤色，验证透明度及实时响应。 |
| 纹理与细节 | 纹理、油画布、降噪、锐化、去锐化、结构、暗角、颗粒 | 已有细节与结构调节、明度/色度降噪、暗角与颗粒。油画布、独立双向锐化及各尺度相互作用按真实出片核对。 |
| 模糊与补光 | 背景虚化、闪光灯、补光、去拖影、氛围光、丁达尔光 | 现有局部模糊、局部曝光与手动已知方向去拖影。验证主体边缘散景、独立照明和高光衰减。未知运动与透明烟雾的真实效果单独验证。 |
| 可编辑元素 | 贴纸、贴图、文字、涂鸦笔、马赛克 | 已有图层混合、贴图、画笔、局部马赛克和绘图。贴纸与可回编文字需检查素材来源、字体/换行、坐标、版本与出口。 |
| 去除与背景 | 消除、背景、变形、形状 | 已有克隆/修补、人物引导抠图、合成、投影与液化。语义去除及任意物体的准确率需另测。区域形状和自由旋转进入先行验收。 |
