# 编辑器与人像深化验收

本表承接 [整仓工作清单](BACKEND-DEPTH.md)。本次补充涉及选区、实时调色、液化、人物几何、妆容、光影与素材合成。登记项以正常产品入口、实际像素、反例、旧配方和交叉操作均有证据时勾选。

## 构图、连续编辑与素材换底

| 链路 | 实现与验收入口 |
| --- | --- |
| 裁切与方向 | 比例在显示方向计算，横竖镜像可与任意直角旋转连续叠加。边缘与四角共用像素裁切规则，参考线单独选择。`packages/editor/test/composed-editing.test.ts` 对不同旧方向和裁切画幅比较逐像素结果。 |
| 液化、修复与局部 | 工具切换保留当前合成画面，笔触通过同一几何与位移场映射到源像素。选择性的局部恢复降低覆盖区位移，保留笔刷外效果。首笔修复、单步撤销重做、笔刷范围和 PNG 与参考引擎逐像素比较均在 `scripts/qa/interactive-preview.browser.mjs`。 |
| 曲线与实时渲染 | 支持直接在线上加点、多点一起移动、精确输入和分通道重置。符合快速路径的曝光、色温／色偏及曲线在源图约 4.19MP 以内使用原尺寸实时渲染，松手后校验参考引擎像素。其他复杂配方和更大源图按工作量选择预览，导出仍用参考渲染。 |
| 草图 | 支持圆角矩形、三角形、菱形、独立标记和气泡图标。元素可调旋转与不透明度、复制或排序。可导入有界的本地 SVG 与浏览器支持的 PNG、JPEG、WebP、BMP、AVIF、GIF 首帧，SVG 作为栅格图层，可导出透明 PNG。 |
| 素材和底图 | 同项目的素材和 Agent 检索图可以在用户确认后替换底图。沿用已保存调色或用空配方开始；原图仍随旧历史保留。生成参考可从当前编辑准确导出。项目权限、并发冲突、历史恢复与重放见 `apps/api/test/ai-decisions.test.ts`。 |

操作行为参照 [Snapseed 编辑堆栈](https://support.google.com/snapseed/answer/6155543)、[Google Photos 构图](https://support.google.com/photos/answer/6128850) 与 [美图手动形变和恢复](https://www.meituxiuxiu.com/zh-Hans/academy/thin-face-and-body)。

## 曲线、专业母版与实时 Agent

| 项目 | 实现与检查 |
| --- | --- |
| 全图与局部曲线 | 新编辑通道显式记录 `pchip-v1`。SVG 与像素算法从相同控制点计算分段三次曲线，保留单调区间和通道之间的独立性。测试覆盖狭窄节点、极值、全图、局部蒙版、分块和旧算法。历史含作用范围、通道和控制点坐标变化，支持重置当前通道或全部通道。 |
| 画布与工作区 | 滚轮按指针位置缩放，双指按中点缩放，画布聚焦时可用加减号和 0。工具范围与滚动位置分开保存，可返回上一工具。面板保存完成的移动、停靠和尺寸步骤，提供恢复上一步。四种视口实际打开了曲线与草图，检查回退、下载、鼠标滚轮、触摸和水平溢出。 |
| 草图 | 同一画布支持笔触、擦除、矩形、椭圆、直线、箭头、文本、图标、当前画布、本地图片和当前项目的已授权素材。元素可选择、移动、删除，文本可修改，图片可缩放。合成 PNG 与当前显示使用同一绘制函数，也可打开为作品或作为生成输入。 |
| 首笔液化 | 进入工具后在空闲预览通道计算当前版本的前缀像素。下一笔只重算其实际覆盖区，使用完全相同的位移场和重建采样。43 笔历史叠加局部质感的两张公开照片，首次更新计算从 1,087／1,453 ms 降至 81／106 ms，预计算耗时另列，输出 RGBA 摘要相同。 |
| 发丝、镜框与口腔 | 分割置信度结合可信主体的连接范围过滤弱残留。手工前景和遮挡区可参与实际透明 PNG 导出。镜框依据眼周附件置信度冻结保护区，白牙仅在可信露齿像素启用。三维光影使用可见网格的深度和法线，避免直接修改不可见面。未覆盖逐齿矫正、隐藏面重建和无提示的通用复杂遮挡。 |
| RAW 和 HDR | 原片面板连接真实 `precisionEdit` 导出，携带原件摘要。Nikon NEF 4284×2844 已完成 PNG16、TIFF16 调色导出。CandleGlass 已完成 float32 EXR 与 PNG16 调色导出，EXR 检查透明度和 HDR 峰值。该入口提供 7 个全局控制和显式色调映射，V4 全栈仍使用 8 位代理。 |
| MCP 与真实模型 | 当前服务通过 MCP 完成工具发现和授权后的资源、配方、历史读取。GPT-6 Luna 的真实 Responses 调用完成 −0.35 EV 编辑，授权事务追加新版本。GPT-Live 1 和 Realtime 2.1 Mini 的双向 PCM 与转录收到实际回执。GPT Image 2.6 Flare 返回一张真实 1024×1024 编辑图。文本与语音的服务端自动写入共用同一候选应用检查。 |

曲线通道、受限工具调用和面部深度的工程依据见 [GIMP 曲线](https://docs.gimp.org/3.0/en/gimp-tool-curves.html)、[MediaPipe 面部关键点](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)、[MediaPipe 分割类别](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter) 和 [MCP 工具](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。

## 先复现的链路

| 验收项 | 真实操作与检查 |
| --- | --- |
| [ ] 选区能旋转及自由调整 | 用宽图、竖图、旋转裁切图操作中心、旋转柄、两轴和多边形顶点。比较实际作用像素、反选、羽化、分块与服务器回放。回退或取消恢复精确结果。 |
| [ ] 选区提示自动退出 | 首次进入、切换区域或重新查看时提示范围。调整照片时检查画面可见，显式显示与当前工具的状态互不覆盖。 |
| [ ] 调色连续响应 | 桌面鼠标和模拟手机触摸分别检查曝光、曲线、饱和度及局部调色。记录输入、首个变化、松手前的画布帧和最终像素，覆盖同时含修复或变形的配方。 |
| [ ] 液化清晰可控 | 用高频纹理、细发丝、文字、半透明边缘和多人主体实测。比较拖动期间、松手、撤销与导出，检查外部像素、边缘重采样和强度极值。 |
| [ ] 交叉联动 | 同图按多种顺序组合几何、局部、液化、手绘、AI 候选、历史回退和团队提交。检查旧配方、多人冲突、范围穿越、权限撤回、导出一致性。 |
| [ ] 参数边界与最小步长 | 对每个可调项核对参数定义、前端滑块和精确输入、共享配方、API、编辑执行及导出。检查最小值、最小值加一步、零前一步、零、零后一步、最大值减一步、最大值、超界输入、撤销重做。只允许单向的控制记录语义。记录最小步在高位深、8 位取整、源分辨率及多次操作后的实际效果。 |
| [ ] 工具归类与接口一致 | 核对全局、局部、几何、人像、手绘、合成、修复及 AI 的入口与共享参数，识别重复语义与跨区影响。验证多端输入、前后端配方回放、版本与历史兼容。 |
| [ ] 图片题材和输入适配 | 对风景、建筑、花卉、生活、运动、夜景、人像、多人、半透明素材及不同尺寸和方向分别验收。记录高光、暗部、肤色、细边、透明像素和高位深输出，避免将同一套自动提亮用于全部题材。 |
| [ ] Agent 工程与编辑联动 | 从当前画面、来源、历史和确认记忆组装 context。核对 prompt、可用技能和 MCP 工具的发现、权限与协议，测试分支、汇合、候选、像素复核、人工接管、撤销和成本。用协作、生成和语音复用同一执行边界，核对流式状态和断线。 |
