## 逐张观察

### 35. hopper-face-1-3.jpg：面部形变与美妆

各格均可见同一戴眼镜人像，没有突然缺失整张脸或整图变成纯色。`smile` 从负值到正值可见嘴角和表情变化；`noseLength` 的强负值明显牵动鼻部及上唇附近，正向结果与负向不同。中性格的五官关系在各行之间看起来相近。`noseTip`、`lipSize`、`browThickness` 的细微差异不足以在此尺度判定定位精度。

口红、眼影和腮红在较强值时可见粉红或紫红色叠加，主要位于嘴唇、眼周和面颊，背景色并未随之整幅改变。修容、高光、眉色和眼下妆的细小差异未作精度结论。眼镜和镜框与处理区域重叠，接触表无法证明遮挡保护、毛发边缘或逐像素选区正确。强鼻部变形可见二维牵拉痕迹；这张表不支持“所有强度均自然”或“已达到精细商业美妆”的结论。

### 36. hopper-grading-1.jpg：阴影、中间调和高光分色

阴影色相行可见制服、旗帜暗部向不同色调变化；中间调色相对脸部和画面暖色关系的影响更明显，呈现暖红、偏黄、较冷与粉紫等区别。色相首尾格在视觉上接近，符合环形色相的预期表现。增大中间调饱和度时暖色更浓；阴影亮度负端压暗制服，正端将暗部抬成灰色，黑位与对比度随之改变。高光亮度的变化主要可在白衬衣、帽徽和亮肤部位观察。

没有看到整图错位或空图。部分分色、平衡行的差异较小，不能证明每一微小步长均有可见且单调的感知变化。强阴影抬升呈现发灰、弱对比观感，强压暗会丢暗部层次；“可调”不代表极值适合成片。

### 37. hopper-hsl-1.jpg：红、橙、黄、绿色域

红色和橙色色相的正负端明显改变脸部和部分旗帜暖色：一端偏紫红，另一端偏黄绿。降低红、橙饱和度时对应区域趋灰，而蓝色背景仍保留颜色；提高时脸部与红色饰物更浓。红、橙明度两端会将脸部压得很暗或提得过白，极高端出现明显的细节损失和斑驳观感。中间的零值格看起来维持原有暖肤色。

黄色和绿色三组行的大部分差异在接触表中很小。不能从这一素材和尺寸推定这些通道失效，也不能宣称已经验证其精细控制质量。没有发现与调节无关的整幅内容消失。

### 38. hopper-hsl-2.jpg：青、蓝、紫、洋红色域

蓝色色相明显改变墙面及旗帜中的蓝色关系，脸部整体暖色较稳定；蓝色饱和度正端使背景和蓝色部分更鲜明，负端趋于中性。蓝色明度很高时，暗制服与旗帜出现明显的亮斑、块状高反差区域，已不适合自然修图；不能把这一极值结果称为细节保持良好。紫色明度正端也能看到制服区域被局部抬亮。

青色、紫色和洋红的部分色相、饱和度变化很小，未判定逐级效果。零值列没有可见的整图形状突变，所有格仍有完整人像。该表支持“分色控制能作用于不同颜色区域”的有限观察，不支持“所有色域均已高质量覆盖”的结论。

### 39. hopper-levels-1.jpg：色阶端点与中间调

输入黑点逐步提高时画面明显压暗，最高端只剩少量亮点与轮廓；输入白点极低时画面近乎白色，向默认白点靠近后恢复可辨的脸部和制服。Gamma 从较低值到较高值呈现暗到亮、再到发灰的变化，`gamma=1` 格可辨为常规对比度的人像。

**表中确有纯色结果**：`outputBlack=1` 格为纯白，`outputWhite=0` 格为纯黑。它们处于输出色阶收拢到单一端点的位置，外观与端点使输出范围退化相符；不能据此称为解码失败，也不能报告“没有黑白空格”。这一观察没有验证用户在实际界面中能否及时理解或恢复退化色阶。

### 42. hopper-retouch.jpg：六类局部信号处理

`uniformity`、`speckle`、`fineLines` 的细微差异不能在该尺寸稳定评价。没有独立的斑点、皱纹真值标注，也未验证是否误抹眼镜边缘或真实皮肤结构，因而**不能将本表解读为祛斑、祛皱、毛孔保真已经达到高质量**。各格未出现缺脸或整图异常变色；极端纹理抑制明显不自然。
