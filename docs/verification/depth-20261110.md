## 图像检查发现及处理

- **旧形变的局部折叠风险**：真实下颌极值图出现折痕。新笔触采用显式 `flow-v1` 连续速度积分，验证正负极值与多种羽化的采样 Jacobian 和反向误差；扩大新下颌影响区以平顺连接脸颊/下巴。历史笔触及目标保留旧算法。极强五官/身形修改仍可能不自然；数值无折叠不代表解剖真实，不能把极值当作推荐预设。
- **美肤缺少足够邻域信息**：新 `guided-v1` 计算 alpha 加权局部统计与2r邻域依赖，将平滑、肌理、色度、高光、脉冲和方向细纹区分。真实肤质接触表已查看；保留纹理不等于重建真实毛孔，细纹抑制也不等于单纹神经识别。
- **补片不一定比扩散好**：新 `exemplar-v1` 在周期纹理损伤的已知真值测试中更好，但三张自然照片的小面积样本中并未优于扩散。保留多方法、供体位置、纹理与搜索预算，不自动将全部历史修复切成新方法。
- **实际模型初始化失败**：相同Worker先创建人脸任务后，分割/姿态创建曾因SDK清空ModuleFactory而失败。固定同源loader使用独立实例查询值，真实两次连续识别验证通过；WASM与权重仍固定hash。
- **跨功能次序**：测试覆盖修复/质感/保护、alpha、整数裁切、四向旋转、翻转、液化及分块一致性；未选区字节和原图不改。取消和预算不足明确失败。
- **手绘中间轨迹丢失**：原先只读取每次pointermove的摘要坐标，抬笔也没有补入最后落点。画笔/橡皮/克隆/选区笔刷现在接收真实coalesced轨迹，单批一次不可变预览，保留短末端，整笔撤销/取消。五种视口下载PNG与参考引擎逐RGBA字节一致，硬边橡皮同路擦除恢复所有源字节。该验证不等于压感、倾斜与全部跨画幅轨迹行为完成。原理参照[W3C Pointer Events 3](https://www.w3.org/TR/pointerevents3/#coalesced-events)。

人工放大查看了肤质、细纹、下颌、眼距、唇妆与身体形变、三种消除方法等接触表，记录问题而不是给全部431项统一“审美通过”。极值形变、细纹/毛发、复杂背景消除和真实高位深显示仍须扩大样本评价。

刷新SSE、切换会话、记忆变更、当前项目/素材撤权、停止授权、旧响应迟到分别受状态与权限检查。未提交预览的撤销会取消预览；外部版本写入后先刷新真实头版本再继续编辑。未知图像/语音/对话结果的运营列表不再只显示固定前100条，分页游标绑定筛选条件和操作者。

再次沿功能交接检查，修正了语音更新作品后误用开场素材ID而无法自动采纳的问题；现在按候选不可变基础版本解析源图。局部质感和三种修复方法接入Agent，可新增也可回调手动操作，自动继承保护区，保留旧算法/手动供体，拒绝覆盖人像模块拥有的操作。五项专用工具测试检查真实像素、透明/选区外字节、保护、裁切与旋转组合、降低强度及归零，不把参数JSON变化算作图像质量通过。

新增/变化局部算子的自动保存必须持有同候选哈希的原尺寸渲染结果；仅512px代理通过不能绕过原图目标像素、供体与工作预算。原尺寸检查沿用16MP输入/输出与全部图层合计16MP上限，每进程最多一个、30秒；模型看到的JPEG仍为缩小图，渲染成功也不等于语义/审美正确。检查失败时不写版本、不消耗编辑步骤、不重发收费请求。

反复使用真实测试库还暴露了诊断命令的累积规模问题：1450条模型目录完整展开后超过256KB子进程输出预算。现改为repeatable-read只读快照、每页200条遍历全部、只保留40条摘要与总数/异常数；测试保持原输出预算，并验证450条后的非法助手配置仍使诊断失败。
