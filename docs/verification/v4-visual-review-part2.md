## 方法与判断边界

每张表按行比较左端、右端、中性样本与中间样本，观察主物体、背景、边缘、颜色、可见细节和整体构图。人物面部表包含脸部裁片，比全身缩略图更容易看见轮廓异常。主观判断只记录在这些图像上实际辨认出的变化。

这些表由最长边不超过 320 像素的 sRGB RGBA8 图像渲染生成，每格再缩放到 160×128 像素区域，最终接触表为 JPEG。缩图、压缩及显示尺度会遮蔽微小噪点、色阶断层、毛孔、细线与一两个像素的蒙版误差。对这些项目，下文明确记为未判定。部分长标签被生成器截断，不能仅凭可见的截断标签声称读到了完整数值。

读图后还只读核对了 `scripts/qa/editor-v4-sweep.ts` 中的接触表生成、参数上下文与几何样例，用来解释已经看到的空画面及背景填充。该代码阅读没有代替读图：例如平移样例明确采用 `fit: 'crop'`，纯背景格因内容移出画幅形成；不是看见空格便自动归类为通过。色调分离的色相样例预设了饱和度，暗角位置/半径样例预设了暗角强度，因此“某一参数为零”也不代表整个配方均中性。

- 颗粒量较高时，深色背景有可见颗粒感。颗粒大小、种子和暗角羽化各小步之间的精确差异，在这张缩图中未判定，不能据此确认粒径或随机复现精度。

## 本组结论与未完成的视觉验证

这组实际图像支持以下有限结论：多数全局颜色、色阶、几何和混合控件具有真实可辨输出；中性样本保持可辨原构图；多种正负调节的外观方向能看见。观察到的全黑、全白与平移空画面有明确极值/固定画幅配置原因，没有在本组发现额外无因全空的样例。

同时，**人像极值的质量风险已实际出现**：颈长会牵动面中部；若干脸型控件会让脸侧轮廓呈波浪状，并扰动背景、帽沿或眼镜。这些观察不能被测试通过数抵消，也不能写成商业级自然美颜、严格区域隔离或背景保护全部达标。报告已将具体表和行通知主代理，供最终交付边界与后续质量改进使用。
