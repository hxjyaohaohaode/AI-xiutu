## 仍需外部或实机验收

- 浏览器的真实桌面/平板/窄手机/横屏、软键盘、触摸、1px落笔、色谱、曲线、所有图层工具与旧源图历史流程，由根任务单独记录，不把这份源码表当作已操作过每个界面。
- 受限浏览器 WebGL 不可用；原生人物分析需要真实目标设备复验。导入严格同源标注后调美颜属于另一条真实流程，应单列。
- 原生 iOS/Android Safari/Chromium、硬件压力、多指和触控笔、屏幕读出程序、低端设备长时间内存稳定性仍需实机覆盖。
- 真模型 API、短信实收、付费订单、内容审核生产账号及大陆三网/代理访问不能用本地测试替身证明，未实测部分须继续保持配置禁用或明确状态。
- 自动人物基础算子不等于商业算法视觉质量；直播、RAW/HDR/高位深印刷、实时多用户像素合并、跨图自动传播并未因本轮框架而自动实现。

本记录中的每个通过项仅限实际跑过的命令和测试范围。本轮全仓的六轮结果、冻结源码及最终提交由根任务记录并同步 GitHub。

## 冻结前根任务补记

后续实测修复取消了“空间不足自动叠放”：停靠的自动让位始终保留真实避让区，紧凑状态使用已有折叠按钮提示看全图/继续调节。最终布局专项16项通过，覆盖四种图片比例的无遮挡几何断言；此前表内11项为当时历史结果。后续通用动效登记增加 `ai-cancellation`，最终78个逻辑角色。实际截图、增量源码复核与全部测试结果以最终总验证为准。
