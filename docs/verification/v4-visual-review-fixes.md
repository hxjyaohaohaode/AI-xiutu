## 结论及边界

实际查看发现的两个问题分别处理：新 V4 自动面部蒙版的外轮廓过渡改为随实际人脸像素尺度变化的向内羽化；自动颈长的圆形推移不能满足保护脸主体与肩膀的语义，因此 V4 将这项能力明确标为尚未实现，不再接受非零值。没有降低曝光、瘦脸或其他控制的范围来掩盖极值问题。

这不是商业级美肤或美体质量验收。自动蒙版仍来自有限分辨率的分割与二维关键点，眼镜、遮挡、发际线和皮肤边界仍可能需要人工精修。强瘦脸和身形极值的邻近背景变形仍是已知限制。所有已保存配方的像素回放继续使用其中保存的原始操作；本次不重写历史配方。
