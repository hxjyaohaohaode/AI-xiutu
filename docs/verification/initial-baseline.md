额外实测：HEX `#FF000080` 能同步到 RGB 255/0/0、HSV 0/100/100 与约 50% 透明度；导入相邻 X 仅差 0.000001 的合法曲线，修改中间点的 Y 后，SVG 显示的 X 坐标依然严格保序。实际点击 PNG 导出后，浏览器产生下载事件、界面显示文件体积；当前浏览器环境未能提供可读下载文件，因此没有声称对该下载文件做了重新解码、尺寸或逐像素复验。完整尺寸导出的算法一致性由单独的实际 Worker 自动测试覆盖。
