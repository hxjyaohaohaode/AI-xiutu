## 3. 已修正的具体问题

### 3.1 原件不是代理图片哈希的附属权限

审查发现媒体链接触发器曾按 `storage_key` 搜索其他素材的原件。用户上传相同代理字节可能意外取得其他空间的原件、EXIF 或母版；两个不同原件产生同一代理也会关联错对象。

已删除该推导路径。普通上传和生成不继承任何已有媒体链接。只有单素材复制或整项目复制，在核验明确来源、当前复制政策、授权和目标编辑权后调用 `prepareAuthorizedMediaCopies`，为目标新增链接并计量。测试分别验证“同代理、无原件授权”和“同代理、两个独立原件”，不是只检查成功复制一条路径。

### 3.2 V4 图层和旧写入口不能成为旁路

原来的 `schemaVersion === 3` 判断会漏掉 V4 的图层来源验证与复制 remap。现在 V3/V4 共同验证所有图层，并由修订插入触发器固定历史依赖。AI 添加图层保留 V4 原配方。

协作租约的保护位于数据库作品/修订写守卫，传统保存、标题、历史恢复、AI 替换、图层采纳和参数采纳都在同一边界内。不能通过换一条 HTTP 路径绕开活动租约。

### 3.3 取消请求不等于解码进程已经停止

另一个进程可能正在解码时，本进程的 `active` map 没有该任务。反复取消不能据此释放预占、删工作目录或绕过全局并发限制。

现将取消状态持久化，同时保留仍处理中任务的 reservation。拥有解码任务的进程通过心跳发现取消并停止；本进程拥有任务时直接等待取消收尾。重复取消不刷新其失联判断时间。HTTP 返回 `cleanupPending`，不会假装已立即清空容量。测试中的远程工作任务是明确通过 SQL 设置的故障夹具，不冒称真的启动了第二个解码服务器。

### 3.4 发布、撤权和存储必须在同一事务边界内

媒体任务接纳和发布会锁定当前有效用户/编辑成员及项目，再锁任务、媒体对象和容量。若成员撤权先完成，发布失败；若发布已拿到权限锁，撤权等待这个合法发布完成。结果成功时释放输入预占并计入真实原件/母版/图块/代理逻辑字节；失败时不留下可读取却未计量的素材。

### 3.5 派发证据独立于数据库恢复点

助手日志不写入提示词、图片、音频或密钥，只保留父任务、类型、序号、请求哈希和时间。写入顺序应为：数据库派发标记提交、日志 fsync、再次核验任务仍可发送和权限仍有效、单次发送。日志返回 `created:false` 是可能已发送的证据，不能用它授权重新发送。

最终文件以排他硬链接从已 fsync 的临时 inode 原子发布；并发实例和进程不能覆盖已有证据。目录条目也 fsync。`assertDatabaseMatches` 检查文件对应派发记录或语音连接，不匹配则阻止新收费请求。`hasEvidence` 供恢复流程在数据库派发行丢失后仍保守判断，损坏/不可读证据不当作“没有发过”。它不是自动补账或自动退款工具。

## 5. 已验证的真实媒体行为

HTTP 测试生成超过 4MiB 的实际 16 位 PNG，通过多个分片上传；同时检查错位、过量、内容不一致与精确重试。完成后使用本机 Linux 限制进程执行真实解码，核对原始字节 SHA-256、16 位 TIFF 母版、DZI 和实际 JPEG 图块、鉴权下载及 16 位转换输出。

第一次流程发现图块接口只接受 `.jpg` 而实际解码器写 `.jpeg`，已修复并完整重跑。测试还导入两个像素相同但原始编码不同的文件，核验它们各自的原件身份。

“原件保留”和“编辑”不混为同一结论：当前浏览器配方编辑是 RGBA8 代理链路；母版转换返回 `X-Editor-Recipe-Included:false`。本测试没有证明任意 200MP、RAW、HDR、多页文件或所有颜色配置文件都能正确处理，也没有证明代理配方已经全尺寸高位深回放。

## 6. 当前明确限制

1. 实时协作采用服务端目标操作与租约。复杂蒙版使用保守包围盒，不是逐像素冲突证明，不是任意离线 CRDT。结构、整配方、几何与修复数组变化需要整作品租约。
2. 同进程事件唤醒，跨进程约 350ms 调度查询；该间隔不是生产网络延迟保证。长轮询并发预算按实例计数。尚未进行跨地域负载或真实弱网长期试点。
3. 会话和事件有容量/寿命预算；过期临时记录按作品访问惰性清理，没有宣称物理实时全局清除。
4. 私人资源记忆是用户显式标签/备注，不是自动人脸身份记忆。长期标注不承诺永久存储；运营身份不扩张资源读取范围。
5. 账本游标固定查询范围和最高 ID，不是跨请求的数据库快照封存。历史缺失的到期金额保留未知，CSV 是逐页导出。
6. 媒体对象按每个独立素材链接计算逻辑容量；软删除不返还原件容量，没有开放自动原件 GC。复制后的已授权副本不因来源退出而被偷偷删除。
7. 写前文件日志能检测“数据库恢复但日志仍在”的不一致；数据库和日志一起丢失、磁盘硬件损坏、跨区域备份一致性不在本次本地测试证明范围。要求服务端文件系统支持排他硬链接、文件及目录 fsync；本轮验证为 Linux，能力不满足时阻断付费请求。试点文件扫描应在规模增长前升级索引/归档并保持核验语义。
8. 未进行真实付费 OpenAI 请求、真实短信、真实商户支付、用户代理订阅或中国大陆不同运营商连通性测试。本地供应商协议夹具只证明适配器交互与本地状态机，不证明外部账户可用或服务质量。
