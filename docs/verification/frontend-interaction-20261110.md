### 停止回执的请求归属

后续源码复核发现，同一账号和作品内，旧轮次的停止响应如果晚于 SSE 终态返回，原来的作用域检查不足以阻止它改写下一轮的进度或错误文案。运行观察现在绑定真实轮次 ID、操作 token 和 AbortController；正常提交、显式核对以及历史中恢复的运行轮次共用同一规则。停止成功与失败只更新原观察者，旧实例的 `finally` 也不能清理新实例。`run.stopping` 更新显示，不更换请求身份。

原停止场景保留刷新恢复、独立协作者、原派发次数、作品版本和部分结果隐藏检查，并先等待匹配轮次的真实停止接口返回 200、正确 ID 及 `stopRequested:true`，再允许本地供应商夹具结束。追加子阶段恢复一轮真实运行任务，调用真实停止接口，仅延后将原回执交付给浏览器；在下一轮已收到增量文本且服务端仍为 `running` 后，再交付旧回执，核对新轮状态不变。额外两次明确准入及四次夹具派发单独报告，不计入原场景的两次派发。局部 Web 类型检查、26 项既有 guards / submission / composer 回归及脚本语法检查通过；新增浏览器行为由包含此修正的主线运行验收，`8d7a112` 的运行不覆盖它。

## 验证边界

本地 HTTP 与测试账号可以验证前后端协议，模拟供应商和合成麦克风不等同于真实付费供应商或物理麦克风。浏览器视口检查不等同于 iOS Safari、Android 真机或实体压感笔验收。像素一致性与执行时间也不代表所有人像的美颜审美合格。

任务页的美元数值来自公开费率与供应商回执，是估算，不是服务点钱包余额或供应商最终发票。语音已知任务可在用量页读取状态，但恢复状态机尚未用这个端点自动解除未知请求；原 key 查询与连接凭证补取仍有接口边界。详细使用与功能限制见 [Web README](../../apps/web/README.md)。
