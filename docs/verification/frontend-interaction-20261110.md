### 首次 GitHub 运行与确定修复

[PR #2](https://github.com/hxjyaohaohaode/AI-xiutu/pull/2) 首次候选 `e52828be02b2c466445de7b6f3728ddc3e99ed59` 的 [运行 42879800436](https://github.com/hxjyaohaohaode/AI-xiutu/actions/runs/42879800436) 已实际完成：仓库测试 842 / 842、类型、构建、生产依赖审计及容器门槛通过；连续曝光、曲线与手机触控的结束像素一致性通过。工作台第一轮前 22 个场景通过，第 23 个场景末尾失败，因此这次运行不能记作整轮成功。

- **版本分支 QA 的无效读地址：** 最后查询分支数量使用了只支持 POST 的 `/projects/:id/artworks`，返回 404。修正为真实 `GET /projects/:id`，保留“唯一一份分支”断言，并核对项目和分支 ID。该场景在失败前已执行实际版本 PNG 像素比较、原 key 恢复和草稿保护；后续未执行场景仍需重跑。
- **连续预览计时的准备帧混入：** 曲线加点只等 DOM 就绪，随后又用第一个移动事件作为起点，造成 `firstChangedMs` 出现负值。现在先等准备操作正式结算，再以真实 DOM 按下事件计时并绑定同一指针；排除按下前帧，不钳制数值，保留原性能与像素门槛。
- **处理线程异常后的重新导入：** 主 Worker 失败时显式失效实例、队列、等待导出和并发导入；保留配方及历史。只有用户明确重新导入才重建，新实例必须先接收完整来源再处理预览或导出。旧消息不能影响新实例，纯单元回归不代替浏览器验证。
- **实际截图复核：** 已读取本次产物中的窄手机、横屏、桌面、真实照片和费率弹窗。截图显示桌面通知遮住工具轨道，已将通知移到顶栏下方；下载反馈改为一句明确的状态说明。最终布局仍以修复后的截图为准。

## 验证边界

本地 HTTP 与测试账号可以验证前后端协议，模拟供应商和合成麦克风不等同于真实付费供应商或物理麦克风。浏览器视口检查不等同于 iOS Safari、Android 真机或实体压感笔验收。像素一致性与执行时间也不代表所有人像的美颜审美合格。

任务页的美元数值来自公开费率与供应商回执，是估算，不是服务点钱包余额或供应商最终发票。语音已知任务可在用量页读取状态，但恢复状态机尚未用这个端点自动解除未知请求；原 key 查询与连接凭证补取仍有接口边界。详细使用与功能限制见 [Web README](../../apps/web/README.md)。
