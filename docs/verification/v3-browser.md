# V3 真实浏览器操作记录

日期：2026-11-09。环境为本轮实际 Chrome 浏览器，页面由真实 Vite 与隔离 API 启动。数据库使用 PGlite，外部 AI、短信与支付关闭。`qa-responsive.html` 只在开发时为同一产品创建独立大小的 iframe，不纳入生产构建；它能检查真实 DOM、画布、点击及布局，不能模拟真实手机内存、触控硬件、麦克风或大陆网络。

本轮没有通过修改 DOM 状态、注入登录态或固定人脸框冒充用户操作。图片来自公开示例照片或独立技术构图；源照片、分析关键点和私有凭据不提交到 Git，仅保留必要截图及去内容化验证数据。产品启动后仍是空工作台。

### 2.1 窄手机面板问题及最后复验

曾实测发现：320×700 恢复 339px 高面板时，照片完整但只有 147×98px。第一次自动叠放修正把照片扩大为296×197.33px，却把主体盖在面板下方；这次修正没有被接受为通过。

最终停靠模式继续严格避让。用户自己保留339px高度时，展开仍完整拟合到较小安全区；原折叠按钮明确标为“看全图”，点击后保留44px标题栏，照片完整恢复到296×197.33px。实际点击“继续调节”后面板恢复339px，曝光仍为-0.35EV，未重置编辑。默认新面板高度277px，用户还可连续调整。

真实键盘缩放也已操作：Alt+方向键一次改变1px，普通方向键按8px改变；390px 面板250→251→347px，随后宽度调至368px。它们不是预设尺寸按钮。

截图：[320px完整照片与收起面板](../screenshots/v3-phone-320-overview.jpg)。大面板、完整照片和所有参数不可能同时无限占用小屏幕；产品通过自主尺寸、停靠、收起/恢复及主参数优先呈现管理这个限制，不以遮住照片冒充可用面积。

### 2.2 主滑条可见性收口

最后一次真实操作在320×700视口验证两种连续高度：339px面板中曝光滑条位于x23/y431，大小274×26px；将面板精确调至277px并切换对比度后，主滑条位于x23/y429，大小274×26px，照片完整显示为240×160px（x40/y117），面板位置x8/y345、大小304×277px。对比度实际调至-12.3%，曝光仍-0.35EV，根滚动尺寸继续320×700。当前主控不再被候选参数网格挤到不可见处。

紧凑模式由手机宽度≤759px或实际面板高度≤420px触发；主滑条优先，候选横向工具带、直方图和帮助信息分层。选择参数若需要，只滚动调参容器，不滚整页。截图：[320px主控最终状态](../screenshots/v3-phone-320-controls.jpg)。

## 3. AI、语音与未配置状态

在实际1440px工作台依次打开图片生成、文本与语音入口：未配置模型且未登录时，模型选择/发送按真实能力禁用并解释原因，没有产生假回复。图片参数控件可见，但禁用发送不构成真实模型调用成功。

当前 HTTP 预览不具备录音所需的安全上下文，语音入口显示 HTTPS 要求和30秒上限。没有打开真实麦克风、发送用户音频或验证语音供应商账户。界面入口与适配器单测不能写成已经完成实时双工语音。

## 4. 导出：已验证编码，未取得下载文件

真实选择并生成 PNG、JPEG、WebP，窗口分别显示约0.60MB、0.12MB、0.11MB文件；来源是本轮建筑图加柔光合成层。导出生成与“点击下载已生成文件”分离，保留链接供用户重试，不因一次点击重新编码。

当前浏览器自动化的下载事件与媒体下载接口均报告下载失败，未取得可读落盘文件。因此没有声称下载文件重新打开、与原尺寸渲染逐像素比较、成功写入相册或所有终端下载正常。实际 Worker 自动测试另行验证原图缓冲与算法输出；它不替代浏览器文件落盘。

交叉代码复核还发现导入期间“交付”入口可以触发旧源导出，已在冻结前加入来源/配方/代次校验和统一入口限制，防止旧结果被新图文件名包装。该竞态由明确时序回归测试验证，不冒称在浏览器里稳定复现过。最后又在浏览器重新导入architecture-china.jpg，从“交付→选择导出格式→生成导出文件”实际生成0.59MB PNG，文件名与当前来源一致；这次没有重复宣称下载已落盘。

## 5. 本轮未进行的浏览器验收

- 未登录团队/运营界面：权限、复制、额度、配置、历史恢复和采纳事务由真实 SQL/API 套件验证，不能记为已操作这些页面的端到端测试。
- 未在真实 iOS/Android/Safari、低端手机、触控笔、软键盘、屏幕阅读器或多指硬件上验收。
- 未验证真实短信、商业模型生成、审核供应商、支付、JMS订阅线路、大陆三网或生产 HTTPS。
- 没有逐帧测量全部动画，也没有对每个可能的 DOM 状态进行1px视觉差分。已查看并调整实际布局；逻辑角色的三端参数及动态减少规则由源码与测试另行覆盖。
- 未使用醒图/美图客户端做实际对照测试，参考依据是用户截图与一手公开说明。
