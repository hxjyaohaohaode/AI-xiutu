# Sketch typefaces

Each face is distributed under the adjacent SIL Open Font License 1.1. Sources are the [Google Fonts collection at 3e566776](https://github.com/google/fonts/tree/3e5667764ccfea32ce0c3d58a3a4756de890adc1/ofl). The WOFF2 conversions preserve the original glyphs and metadata. The four CJK chooser specimens are small subsets of the corresponding full face and use separate CSS names. The full CJK faces load when applied to a text object. IBM Plex Mono, Playfair Display and DM Serif Text use the upstream Google Fonts Latin WOFF2 builds. System font fallbacks supply missing characters. All font requests are same-origin.
