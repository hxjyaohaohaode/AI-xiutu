# About 图像

本目录的展示图与示例分开管理。界面图来自实际浏览器中的映间工作台，不是生成的界面模型；只转码为 WebP，没有补画控件或替换照片中的编辑结果。

| 文件 | 内容 | 原始尺寸 |
| --- | --- | --- |
| `workspace-{zh-CN,zh-TW,en}.webp` | 海岸示例、实际色温参数与工作台 | 1440 × 960 |
| `local-{zh-CN,zh-TW,en}.webp` | 实际创建并旋转的多边形选区；未开启持续红色覆盖 | 1440 × 960 |
| `portrait-{zh-CN,zh-TW,en}.webp` | 本机模型识别成功后的人物、美肤参数与原图 | 1440 × 960 |
| `layers-{zh-CN,zh-TW,en}.webp` | 独立绘制图层、4 px 笔刷和真实绘制的一笔 | 1440 × 960 |
| `phone-{zh-CN,zh-TW,en}.webp` | 手机常规调节状态，照片与 44 px 滑杆触控区域同时保留 | 390 × 844 |
| `coast.webp` | AI 生成的海岸练习照片 | 1536 × 1024 |
| `portrait.webp` | AI 生成的自然光人像练习照片 | 1536 × 1024 |
| `color-study.webp` | AI 生成的静物练习照片 | 1536 × 1024 |

生成的照片在 About 中明确标注为练习素材，并可通过同源地址直接带入实际编辑器。`ColorStudy` 使用与工作台相同的编辑引擎生成交互预览。界面图中的“云端暂不可用”来自仅部署静态前端的验收站点，未隐藏或替换成虚构的云端成功状态。

图层、选区等已保存对象的名称属于创作数据，切换语言保留原值。界面标题、参数、状态与操作控件按语言切换。人像截图保持美颜参数为零，展示识别和控制能力，不宣称没有实际执行过的修饰效果。

源码适配与许可见 `src/about/effects/REFERENCE_STUDY.md` 和 `LICENSE.react-bits.md`；交互、构建与测试边界见 `docs/verification/frontend-immersive-20261111-tests.md`。
