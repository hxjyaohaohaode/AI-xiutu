# React Bits in the editing workspace and About page

These source files are pinned to [DavidHDev/react-bits at 9d9c687dc4f55b23539aa5417b703078047efa74](https://github.com/DavidHDev/react-bits/tree/9d9c687dc4f55b23539aa5417b703078047efa74). They are used as part of the application. See the included license. Card Swap and Reflective Card use the existing Phosphor icons. Application adapters supply first-party sample images and localized labels.

Light Rays is used in the opening. Target Cursor follows the pointer across the overview. Morph Slider illustrates color grading. Orbit Images accompanies the portrait section. Card Swap and Bounce Cards show sketch elements. Strands renders the recorded assistant call orb and the live workspace voice orb. Holo Card draws the foil around the replay. Folder and Drift Wall accompany the library. The delivery background uses two lightweight, rotating photo lanes based on the Flying Posters layout. Bounce Cards is also used for the editor image layer picker.

[Prompt Bar](https://reactbits.dev/c/micro/prompt-bar) provides source and command menus, model selection, and the morphing send/stop control in the studio. [Lattice Loader](https://reactbits.dev/c/micro/lattice-loader) covers submission and waiting. [Thought Line](https://reactbits.dev/c/micro/thought-line) folds public execution events and uses the turn receipt for its final state. [Voice Pill](https://reactbits.dev/c/micro/voice-pill) displays the actual microphone level and elapsed time while the voice connection owns the stream. The sketch formatting controls reuse [Warm Tooltip](https://reactbits.dev/c/micro/warm-tooltip) from `components/control-motion`.

The workspace [Dock](https://reactbits.dev/components/dock) uses the [pinned TS/CSS source](https://github.com/DavidHDev/react-bits/tree/9d9c687dc4f55b23539aa5417b703078047efa74/src/ts-default/Components/Dock) as its reference for cosine-squared falloff, resting centers, launch rebound and focus handling. The adapter keeps the editor's stable hit areas, independent touch scrolling and persistent selected state.
About uses the upstream Orbit Images path and card positioning, the Card Swap depth and drag physics, the Bounce Cards spring motion, the Holo Card foil shader, and the Drift Wall perspective and parallax. The product adapters use first-party assets and tune sizes, paths and contrast. Drift Wall adds tile activation and an option to drift without duplicating visible photos. Holo Card keeps its original image path and supports a transparent foil pass for the accessible HTML call replay.
