# React Bits in the editing workspace and About page

These source files are pinned to [DavidHDev/react-bits at 9d9c687dc4f55b23539aa5417b703078047efa74](https://github.com/DavidHDev/react-bits/tree/9d9c687dc4f55b23539aa5417b703078047efa74). They are used as part of the application. See the included license. Card Swap and Reflective Card use the existing Phosphor icons. Application adapters supply first-party sample images and localized labels.

Grid Motion, Light Rays and Target Cursor are used in the opening. Grid Distortion, Pixel Transition and Morph Slider illustrate edits. Orbit Images accompanies the portrait section. Card Swap and Bounce Cards show separate layers. Laser Flow surrounds the assistant. Circular Gallery, Folder and Drift Wall accompany the library. Flying Posters and Reflective Card illustrate delivery. Strands is used in the real voice session. Bounce Cards is also used for the editor image layer picker.

The workspace [Dock](https://reactbits.dev/components/dock) uses the [pinned TS/CSS source](https://github.com/DavidHDev/react-bits/tree/9d9c687dc4f55b23539aa5417b703078047efa74/src/ts-default/Components/Dock) as its reference for cosine-squared falloff, resting centers, launch rebound and focus handling. The adapter keeps the editor's stable hit areas, independent touch scrolling and persistent selected state.
