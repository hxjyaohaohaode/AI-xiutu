# Reference interaction study

This record covers bounded, actual public-browser interaction and authoritative source reads during the current About redesign. It does not claim exhaustive browsing of every page or paid component. No sign-in, purchase or paid template download occurred.

## React Bits

| Public page                                                                                                        | Actual operation and observed result                                                                                                                                                                                                                                                                                            | Applied design decision                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Ribbons](https://www.reactbits.dev/animations/ribbons)                                                            | Opened Preview, read the 15-property table, changed Length using End (value became 3), dragged the pointer across the preview, opened Code and read its full spring-chain/WebGL implementation. The final cloud-browser captures did not show the ribbon trail clearly, so they are not evidence of its visual motion quality.  | Adapt its seeded spring chain, fixed timestep and lens profile into Canvas 2D with a clearly visible ink/orange trail, static fallback, bounded pixel budget and idle stop. Verify the implemented result in the actual application separately. |
| [Tilted Card](https://www.reactbits.dev/components/tilted-card)                                                    | Waited for the album preview to load; moved across it. DOM style changed to rotateX -0.642°, rotateY 1.76°, scale 1.0442 and glare 0.442; screenshot showed the lifted cover and pointer tooltip. Click changed aria-pressed to true and showed the reverse track list. Opened Code and read the spring/pointer implementation. | Use pointer geometry and damped settling for actual workspace imagery, capped at 4° with keyboard focus handling. No gyroscope request, arbitrary flips or transform on editing controls.                                                       |
| [Scroll Reveal](https://www.reactbits.dev/text-animations/scroll-reveal)                                           | Scrolled the demo container; its scrollTop reached 934 while the text block rotation/opacity progressed. A later capture showed the revealed text within the demo. Opened Code and read the GSAP ScrollTrigger and per-piece opacity/lift mapping.                                                                              | Apply piece progression to native document scroll. The product page has no nested demo scroller and does not intercept the wheel; nonessential blur is omitted.                                                                                 |
| [Flowing Menu](https://www.reactbits.dev/components/flowing-menu)                                                  | Observed entry movement of the white band and image marquee, moved between menu rows, inspected the visible Sonoma band/track transform, and selected Mobile · 375px (pressed state changed). Read the public TypeScript source.                                                                                                | Feature previews can react to hover and keyboard focus, with continuous page sections remaining reachable by ordinary scrolling. No mandatory click to reveal every capability.                                                                 |
| [Threads source](https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/Backgrounds/Threads/Threads.tsx) | Read the complete authoritative source, including instanced line geometry, cursor parting, 1,920px render cap, IntersectionObserver and visibility suspension. No claim of a separate live Threads preview session.                                                                                                             | Retain bounded render sizes and offscreen scheduling; avoid adding another WebGL workload alongside the real image engine.                                                                                                                      |

The first captures of some component previews were empty while their lazy content loaded. Tilted Card was re-inspected only after the actual figure and image appeared. This load state is kept distinct from a working visual result. The free source uses MIT + Commons Clause; the exact retrieved license is included alongside the adaptations.

## Official product sites

The following is a second, bounded public-browser pass through the four sites requested alongside MiMo. These are live observations of the pages served during the work, rather than claims about their historical design. Marketing performance claims and example conversations on those sites were not used as evidence of AI-xiutu capabilities.

| Public page                              | Actual operation and observed result                                                                                                                                                                                                                                                                                                                                                                                                                         | Applied design decision                                                                                                                                                                                                                                    |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [DeepSeek](https://www.deepseek.com/en/) | The first navigation displayed a client-side exception. One normal reload recovered the homepage. Viewed the blue gradient/grid hero, large entry surface, three product destinations and language switch. Dismissed the cookie choice with necessary cookies only and scrolled to the footer; the header condensed into a translucent capsule. No chat prompt was sent.                                                                                     | Give the product one clear opening action and a secondary local-entry action; keep navigation compact and the page reachable through native scrolling. Retain product-specific controls instead of copying a chatbot entry field.                          |
| [xAI](https://x.ai/)                     | Viewed the large rotating hero word and the row of animated chat/code/product panels. Moved the pointer onto Products: a two-column menu opened with product descriptions and an animated example. Moved away and scrolled to the API section. Clicked TypeScript and verified that the displayed code changed from Python to TypeScript.                                                                                                                    | Show recognizable interface imagery and a concise explanation together. Use hover/focus to preview a feature while keeping the full product story in normal document flow. Limit dynamic examples to visible sections.                                     |
| [OpenAI](https://openai.com/)            | Viewed the sparse prompt-led hero and large visual story cards. Clicked More and observed the extra shortcut; expanded and collapsed the Products menu. Scrolled the document (scrollTop was observed at 1,872px during the pass) and inspected the image-led research and customer-story grids with the header remaining available. No prompt was submitted and no account destination was opened.                                                          | Establish a hierarchy between one primary action, a few supporting links, and substantial product imagery. Place explanatory copy next to actual screenshots; use editorial image proportions rather than repeating generic feature cards.                 |
| [Anthropic](https://www.anthropic.com/)  | Viewed the warm paper background, oversized mixed serif/sans introduction and full-width visual panel. Clicked Play video and observed its label become Pause video; it later returned to Play before a pause attempt, so no uninterrupted playback duration is claimed. Scrolled to the lower illustration cards; initial blank space populated with the loaded collages on a later capture. Opened Research and verified its expanded menu and categories. | Adapt warm neutral contrast, restrained type hierarchy and useful illustrations. Give animation an explicit motion boundary and static content fallback; preserve visible reading content during lazy loading instead of leaving unexplained empty panels. |

MiMo was investigated separately by the parent implementation agent; its pointer brush-trail observation is not duplicated here. Proprietary site source, images, videos and marketing copy were not copied into the product. The reusable source adaptation in this directory is the attributed React Bits work described above.
