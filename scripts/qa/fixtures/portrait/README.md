# Public portrait QA fixtures

GitHub Actions reads these three JPEGs locally so the checks can run when Wikimedia is rate limiting requests. The files are byte-identical to the originals. The [input manifest](../../portrait-real-world-inputs.json) pins each file's byte count and SHA-256.
